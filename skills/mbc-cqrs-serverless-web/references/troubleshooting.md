# Troubleshooting

Find the symptom, check the cause, then confirm the fix in the browser (and the console).

| Symptom                                                                              | Usual cause                                                                                                                                                        | Fix                                                                                                                                                                                |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Screens unstyled, or buttons transparent / inputs without borders / links uncoloured | no stylesheet, or `styles.layer.css` with Tailwind v3 (its unlayered reset beats every layer)                                                                      | import `styles.css` with Tailwind v3; `styles.layer.css` only with v4, _before_ Tailwind                                                                                           |
| Library styles lose to the app's on Tailwind v3.0–3.3                                | equal specificity, app CSS loaded later                                                                                                                            | load the library stylesheet after the app's CSS                                                                                                                                    |
| A library class in `className` does nothing                                          | only classes the library ships exist in its CSS                                                                                                                    | use the app's own classes for new styling                                                                                                                                          |
| Dialog / menu without theme colours                                                  | `--mbc-*` variables set on a wrapper instead of `:root`                                                                                                            | set the variables on `:root` (or `[data-mbc]`)                                                                                                                                     |
| "You're importing a component that needs useState…" / Server Component errors        | a screen or page imported in a Server Component                                                                                                                    | render it from a file marked `'use client'`; only `/core` is server-safe                                                                                                           |
| A constant from `/mbc` is a strange object on the server                             | it was imported through a client module                                                                                                                            | import non-component values from the package's server-safe entry (`/core`, or `/mbc`'s API values)                                                                                 |
| Hydration mismatch                                                                   | the app's `tenantCode` or props differ between server and client (`window`, cookies read only in the browser, `Date.now()`)                                        | compute them on the server and pass them down; the package itself formats times after hydration                                                                                    |
| Page opens "not found" / wrong item after navigating                                 | ids not encoded in `href`, or route params not decoded                                                                                                             | `encodeURIComponent` in `hrefOf`; `decodeURIComponent` on params before passing `id`                                                                                               |
| A new item opens with "load failed" right after creating it                          | the client has no `realtime`, so the page moved on before the backend stored the item                                                                              | configure `realtime`, or accept the delay                                                                                                                                          |
| Saves end with "outcome unknown"                                                     | a timeout (a command waits 60 s for the backend's finish message) or a dropped connection: the save may have gone through                                          | reload to check. Connected pages use the 60 s default; in your own `createMasterApi` calls pass `timeoutMs` per write. The client's `timeoutMs` option covers single HTTP requests |
| Every save times out                                                                 | realtime connects but no "finished" message arrives: wrong AppSync URL/auth, or a tenant mismatch                                                                  | check `realtime` config and the tenant the backend uses                                                                                                                            |
| Every save times out with `transport: 'events'`                                      | `namespace` differs from the backend's `APPSYNC_EVENTS_NAMESPACE`, the backend's `NOTIFICATION_TRANSPORTS` lacks `appsync-event`, or `url` is the GraphQL endpoint | match the namespace; enable the transport on the backend; use the Events endpoint (`…/event`)                                                                                      |
| All of the tenant's own items open read-only                                         | `tenantCode()` returns a different tenant than the items'                                                                                                          | return the tenant the backend uses (the comparison ignores case)                                                                                                                   |
| Rich editors stay plain text boxes                                                   | peers not installed, or `components={editorRenderers}` / `jsonEditor` not passed                                                                                   | install the peers; pass the props; they appear after mount                                                                                                                         |
| Editors blank in production                                                          | Content Security Policy                                                                                                                                            | allow `style-src 'unsafe-inline'`, `worker-src blob:`, `script-src data:`                                                                                                          |
| Types: "Cannot find module '…/styles.css'"                                           | plain `tsc` on TypeScript 6                                                                                                                                        | add `declare module '*.css'` in a `.d.ts`                                                                                                                                          |
| Duplicate React context / provider seems ignored                                     | two copies of ui-web or client-web (mismatched versions)                                                                                                           | install siblings at exactly the screen package's version; dedupe                                                                                                                   |

Still stuck: read the installed README's section for that screen, and reproduce with the smallest page (one provider, one screen) to rule the app's code in or out.
