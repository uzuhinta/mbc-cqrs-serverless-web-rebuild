## Review Focus

Inputs v0 data really contains, each pinned by a test in the task that owns it:

1. **A field whose stored `dataType` this version does not know** (`'text'`, a future type) → treated as `string`, so the record still loads and saves. _Task 2: "treats an unknown stored type as string"._
2. **Number options stored as strings, numbers, `''` or `null`** (`length: '255'`, `maxRow: 3`, `min: null`) → read as numbers or "not set", never `NaN` rules. _Task 1: "fills what v0 sometimes left out"; Task 2: `numberOption` tests._
3. **A record holding attributes no field owns, or values of the wrong type** (`price: 980` for a number field stored as text, `active: 'true'`, JSON stored as a string) → an untouched save sends them back unchanged; an edit keeps their representation. _Task 3: "saves an untouched record…", "adds only v0’s code / name / seq copies…", "stores edits the way v0 did…"._
4. **A setting without `code` / `name` fields** → record-level code and name inputs appear and are sent as the record's code and name, never as attributes. _Task 3: "never writes the record-level code / name inputs…"; Task 5: "uses typed code / name…"._
5. **Bulk JSON whose mapper throws, returns `null`, or maps a setting on a data list** → reported per entry with its index, skipped, or refused. _Task 7: mapper tests._

## Rulings already made (do not undo)

- **`parseBulkJson(text, { screen })`** replaces the spec's `{ kind }`: the settings list accepts settings and data (v0's mixed import), a setting's data list accepts data only.
- **Form functions take `fields`** (`dataFields(setting)`), not the setting: v0 shows record-level code / name inputs when a setting lacks those fields, and the same list drives inputs, validation and saving.
- **Stored representation is kept:** number inputs are saved as strings as v0 did, unless the stored value was a number; booleans stored as `'true'` / `'false'` stay strings; untouched inputs keep the stored value; an empty input adds no new key; v0's `code` / `name` / `seq` copies in `attributes` are kept.
- **Changes from v0, all documented in MIGRATION later (M8):** a required switch never blocks saving (v0 required it to be on); string `length` applies even when `maxRow` makes the input multi-line; `min` / `max` are not checked on an empty number; field definitions also need unique physical names without `.`, `[` or `]` and an allowed type; `text-area` offers `maxRow`; bulk items need text `code` / `name` and every bad entry is reported (v0 stopped at the first); the import sample is indented; a data-only copy with no records chosen sends `{ mode: 'ALL' }` without an empty `id` list.
- **`toDataPayload` throws** when the code field is `auto_number` and no `generatedCode` is given — a programming error, caught by tests in M5.

`packages/master-web/src/core/parse.ts`:

```ts
import { z } from 'zod'

import type { MasterData, MasterSetting } from './types'

export type ParseResult<T> =
  { success: true; data: T } | { success: false; error: z.ZodError }

/** v0 sometimes stores `null` where a value is optional. */
const optional = <T extends z.ZodType>(schema: T) =>
  z
    .preprocess(
      (value) => (value === null ? undefined : value),
      schema.optional()
    )
    .optional()

/** v0 stores flags as booleans, older data as 'true' / 'false'. */
const flag = z.preprocess(
  (value) => value === true || value === 'true',
  z.boolean()
)

const stringOrNumber = optional(z.union([z.string(), z.number()]))

const MasterFieldSchema = z.looseObject({
  physicalName: z.string(),
  name: z.string(),
  description: optional(z.string()),
  dataType: z.string(),
  isRequired: flag,
  isShowedOnList: flag,
  defaultValue: z.unknown().optional(),
  length: stringOrNumber,
  pattern: optional(z.string()),
  min: stringOrNumber,
  max: stringOrNumber,
  maxRow: stringOrNumber,
  dataFormat: optional(z.string()),
  formatCode: optional(z.string()),
  formatName: optional(z.string()),
  prefix: optional(z.string()),
  postfix: optional(z.string()),
})

const entity = {
  id: z.string(),
  pk: z.string(),
  sk: z.string(),
  code: z.string(),
  name: z.string(),
  version: z.preprocess((value) => value ?? 0, z.number()),
  tenantCode: optional(z.string()),
  isDeleted: optional(z.boolean()),
}

const MasterSettingSchema = z.looseObject({
  ...entity,
  attributes: z.preprocess(
    (value) => value ?? {},
    z.looseObject({
      description: z.preprocess(
        (value) => (typeof value === 'string' ? value : ''),
        z.string()
      ),
      fields: z.preprocess((value) => value ?? [], z.array(MasterFieldSchema)),
    })
  ),
})

const MasterDataSchema = z.looseObject({
  ...entity,
  seq: optional(z.number()),
  attributes: z.preprocess(
    (value) => value ?? {},
    z.record(z.string(), z.unknown())
  ),
})

function wrap<T>(result: z.ZodSafeParseResult<unknown>): ParseResult<T> {
  return result.success
    ? { success: true, data: result.data as T }
    : { success: false, error: result.error }
}

/** Reads a stored setting the way v0 wrote it; unknown keys are kept. */
export function parseMasterSetting(input: unknown): ParseResult<MasterSetting> {
  return wrap(MasterSettingSchema.safeParse(input))
}

/** Reads a stored data record the way v0 wrote it; unknown keys are kept. */
export function parseMasterData(input: unknown): ParseResult<MasterData> {
  return wrap(MasterDataSchema.safeParse(input))
}
```

```ts
import { isMasterFieldType, type MasterFieldType } from './field-type-names'
import type { MasterError } from './errors'
import type { MasterField } from './types'

/** What a field's input holds: text, a switch, or a list of texts (`array`). */
export type FormValue = string | boolean | string[]

/** Definition inputs the settings editor shows for a type, besides the common ones. */
export type FieldOptionName =
  'length' | 'pattern' | 'min' | 'max' | 'maxRow' | 'format'

export type FieldTypeDefinition = {
  options: readonly FieldOptionName[]
  /** Whether a definition can carry a default value (v0: not `array` / `auto_number`). */
  hasDefault: boolean
  /** v0's value for an empty field in the record JSON view. */
  empty: unknown
  /** Stored value → input value. Never throws, whatever was stored. */
  toFormValue(stored: unknown): FormValue
  /** Input value → stored value. `previous` is what was stored before. `undefined` removes the key. */
  fromFormValue(form: FormValue, previous: unknown): unknown
  /** Type rules for a non-empty value; `required` is checked separately. */
  validate(form: FormValue, field: MasterField): MasterError | null
  /** Whether the input counts as empty for `isRequired`. */
  isEmpty(form: FormValue): boolean
}

const INTEGER = /^-?[0-9]+$/

/** v0 stores numeric options as strings; '' and non-numbers mean "not set". */
export function numberOption(value: unknown): number | undefined {
  if (typeof value === 'number')
    return Number.isFinite(value) ? value : undefined
  if (typeof value === 'string' && value.trim() !== '') {
    const number = Number(value)
    return Number.isFinite(number) ? number : undefined
  }
  return undefined
}

function toText(stored: unknown): string {
  if (stored === undefined || stored === null) return ''
  if (typeof stored === 'string') return stored
  if (typeof stored === 'object') return JSON.stringify(stored)
  return String(stored)
}

function asString(form: FormValue): string {
  if (typeof form === 'string') return form
  return Array.isArray(form) ? form.join('\n') : String(form)
}

function lengthAndRows(value: string, field: MasterField): MasterError | null {
  const max = numberOption(field.length)
  if (max !== undefined && value.length > max)
    return { key: 'maxLength', params: { max } }
  const rows = numberOption(field.maxRow)
  if (rows !== undefined && rows >= 1 && value.split('\n').length > rows)
    return { key: 'maxRows', params: { max: rows } }
  return null
}

function matchesPattern(value: string, field: MasterField): MasterError | null {
  if (!field.pattern) return null
  try {
    if (new RegExp(field.pattern).test(value)) return null
  } catch {
    // v0: a pattern that does not compile rejects every value.
  }
  return { key: 'pattern', params: { name: field.name } }
}

function textType(
  options: readonly FieldOptionName[],
  check?: (value: string, field: MasterField) => MasterError | null
): FieldTypeDefinition {
  return {
    options,
    hasDefault: true,
    empty: '',
    toFormValue: toText,
    fromFormValue: (form) => asString(form),
    validate: (form, field) => {
      const value = asString(form)
      return value === '' || !check ? null : check(value, field)
    },
    isEmpty: (form) => asString(form) === '',
  }
}

const number: FieldTypeDefinition = {
  options: ['min', 'max'],
  hasDefault: true,
  empty: 0,
  toFormValue: toText,
  // v0 saves what the input holds (a string); a value stored as a number stays a number.
  fromFormValue: (form, previous) => {
    const value = asString(form).trim()
    if (typeof previous !== 'number') return value
    return value === '' ? undefined : Number(value)
  },
  validate: (form, field) => {
    const value = asString(form).trim()
    if (value === '') return null
    if (!INTEGER.test(value)) return { key: 'integer' }
    const min = numberOption(field.min)
    if (min !== undefined && Number(value) < min)
      return { key: 'min', params: { min } }
    const max = numberOption(field.max)
    if (max !== undefined && Number(value) > max)
      return { key: 'max', params: { max } }
    return null
  },
  isEmpty: (form) => asString(form).trim() === '',
}

const boolean: FieldTypeDefinition = {
  options: [],
  hasDefault: true,
  empty: false,
  toFormValue: (stored) => stored === true || stored === 'true',
  // Definitions and older records hold 'true' / 'false'; keep the stored representation.
  fromFormValue: (form, previous) => {
    const value = form === true
    return typeof previous === 'string' ? String(value) : value
  },
  validate: () => null,
  // `false` is an answer, so a required switch never blocks saving.
  isEmpty: () => false,
}

const array: FieldTypeDefinition = {
  options: [],
  hasDefault: false,
  empty: [],
  toFormValue: (stored) => {
    if (Array.isArray(stored)) return stored.map(toText)
    return stored === undefined || stored === null || stored === ''
      ? []
      : [toText(stored)]
  },
  fromFormValue: (form) => {
    if (Array.isArray(form)) return [...form]
    const value = asString(form)
    return value === '' ? [] : [value]
  },
  validate: () => null,
  isEmpty: (form) =>
    Array.isArray(form) ? form.length === 0 : asString(form) === '',
}

const json: FieldTypeDefinition = {
  options: [],
  hasDefault: true,
  empty: '',
  toFormValue: (stored) => {
    if (stored === undefined || stored === null) return ''
    return typeof stored === 'string' ? stored : JSON.stringify(stored, null, 2)
  },
  // v0 saves parsed JSON; an empty input stays ''. Text that does not parse is
  // returned as-is (validation reports it before anything is saved).
  fromFormValue: (form) => {
    const value = asString(form)
    if (value.trim() === '') return ''
    try {
      return JSON.parse(value) as unknown
    } catch {
      return value
    }
  },
  validate: (form) => {
    const value = asString(form)
    if (value.trim() === '') return null
    try {
      JSON.parse(value)
      return null
    } catch {
      return { key: 'json' }
    }
  },
  isEmpty: (form) => asString(form).trim() === '',
}

export const fieldTypes: Readonly<
  Record<MasterFieldType, FieldTypeDefinition>
> = {
  string: textType(
    ['length', 'pattern'],
    (value, field) =>
      lengthAndRows(value, field) ?? matchesPattern(value, field)
  ),
  number,
  auto_number: { ...textType(['format']), hasDefault: false },
  boolean,
  date: textType([]),
  array,
  json,
  'text-area': textType(['maxRow'], lengthAndRows),
  'text-html': textType([]),
  'text-markdown': textType([]),
}

/** The field's type; a stored type this version does not know behaves as `string`. */
export function fieldTypeOf(
  field: Pick<MasterField, 'dataType'>
): FieldTypeDefinition {
  return isMasterFieldType(field.dataType)
    ? fieldTypes[field.dataType]
    : fieldTypes.string
}
```

```ts
import { fieldTypeOf, type FormValue } from './field-types'
import type { MasterData, MasterField, MasterSetting } from './types'

/** Input values keyed by `physicalName`. */
export type MasterFormValues = Record<string, FormValue>

/**
 * v0 shows its own required code and name inputs when the setting has no
 * `code` / `name` field. They are record-level values, not attributes.
 */
export const ENTITY_CODE_FIELD: MasterField = Object.freeze({
  physicalName: 'code',
  name: '',
  dataType: 'string',
  isRequired: true,
  isShowedOnList: true,
})
export const ENTITY_NAME_FIELD: MasterField = Object.freeze({
  physicalName: 'name',
  name: '',
  dataType: 'string',
  isRequired: true,
  isShowedOnList: true,
})

/** True for the record-level code / name inputs added by `dataFields`. */
export function isEntityField(field: MasterField): boolean {
  return field === ENTITY_CODE_FIELD || field === ENTITY_NAME_FIELD
}

/** The inputs of a data record: the setting's fields, plus code / name when the setting lacks them. */
export function dataFields(setting: MasterSetting): MasterField[] {
  const fields = setting.attributes.fields
  const has = (name: string) =>
    fields.some((field) => field.physicalName === name)
  return [
    ...(has('code') ? [] : [ENTITY_CODE_FIELD]),
    ...(has('name') ? [] : [ENTITY_NAME_FIELD]),
    ...fields,
  ]
}

/**
 * Input values: a stored record's values (its own code, name and seq win over
 * the same keys in `attributes`, as in v0), or each field's default for a new record.
 */
export function toFormValues(
  fields: readonly MasterField[],
  data?: MasterData
): MasterFormValues {
  const stored: Record<string, unknown> | undefined = data && {
    ...data.attributes,
    code: data.code,
    name: data.name,
    seq: data.seq ?? 0,
  }
  const values: MasterFormValues = {}
  for (const field of fields) {
    const source = stored ? stored[field.physicalName] : field.defaultValue
    values[field.physicalName] = fieldTypeOf(field).toFormValue(source)
  }
  return values
}

function sameFormValue(a: FormValue, b: FormValue): boolean {
  if (Array.isArray(a) && Array.isArray(b))
    return a.length === b.length && a.every((item, index) => item === b[index])
  return a === b
}

/**
 * Attributes to save. Keys no field owns are kept; a field whose input is
 * unchanged keeps its stored value exactly (type included); an empty input
 * adds no key; record-level code / name inputs are not attributes.
 */
export function fromFormValues(
  fields: readonly MasterField[],
  values: MasterFormValues,
  previous: Readonly<Record<string, unknown>> = {}
): Record<string, unknown> {
  const attributes: Record<string, unknown> = { ...previous }
  for (const field of fields) {
    const name = field.physicalName
    const form = values[name]
    if (form === undefined || isEntityField(field)) continue
    const type = fieldTypeOf(field)
    const before = previous[name]
    const stored = name in previous
    // An empty input does not add a key the record never had.
    if (!stored && sameFormValue(form, type.toFormValue(undefined))) continue
    const next =
      stored && sameFormValue(form, type.toFormValue(before))
        ? before
        : type.fromFormValue(form, before)
    if (next === undefined) delete attributes[name]
    else attributes[name] = next
  }
  return attributes
}

const pad = (value: number) =>
  String(Math.floor(Math.abs(value))).padStart(2, '0')

/** v0's stored date: local date and time with the offset, e.g. 2026-10-07T00:00:00+09:00. */
export function formatDateValue(date: Date): string {
  const offset = -date.getTimezoneOffset()
  return (
    `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())}` +
    `T${pad(date.getHours())}:${pad(date.getMinutes())}:${pad(date.getSeconds())}` +
    `${offset >= 0 ? '+' : '-'}${pad(offset / 60)}:${pad(offset % 60)}`
  )
}
```

```ts
import type { MasterError } from './errors'
import { fieldTypeOf } from './field-types'
import type { MasterField } from './types'
import type { MasterFormValues } from './values'

export type MasterDataErrors = Record<string, MasterError>

/**
 * v0's rules for a data record, one error per field. On create the code is
 * always required and may not be only spaces (unless it is generated); on
 * update the code is read-only and not checked.
 */
export function validateMasterData(
  fields: readonly MasterField[],
  values: MasterFormValues,
  { mode }: { mode: 'create' | 'update' }
): MasterDataErrors {
  const errors: MasterDataErrors = {}
  for (const field of fields) {
    const name = field.physicalName
    const type = fieldTypeOf(field)
    const form = values[name] ?? type.toFormValue(undefined)
    if (name === 'code') {
      if (mode === 'update' || field.dataType === 'auto_number') continue
      if (type.isEmpty(form)) {
        errors[name] = { key: 'required' }
        continue
      }
      if (typeof form === 'string' && form.trim() === '') {
        errors[name] = { key: 'blank' }
        continue
      }
    } else if (field.isRequired && type.isEmpty(form)) {
      errors[name] = { key: 'required' }
      continue
    }
    const error = type.validate(form, field)
    if (error) errors[name] = error
  }
  return errors
}
```

```ts
import type { MasterData, MasterSetting } from './types'
import { dataFields, fromFormValues, type MasterFormValues } from './values'

/** `POST /api/master-data/create` body. */
export type MasterDataCreateBody = {
  settingCode: string
  code: string
  name: string
  seq?: number
  attributes: Record<string, unknown>
}

/** `PUT /api/master-data/:id` body. */
export type MasterDataUpdateBody = {
  name: string
  seq: number
  attributes: Record<string, unknown>
}

const SETTING_PREFIX = 'MASTER_SETTING#'

/** The setting's own code; list rows may carry it as `MASTER_SETTING#<code>`. */
export function settingCodeOf(setting: Pick<MasterSetting, 'code'>): string {
  return setting.code.startsWith(SETTING_PREFIX)
    ? setting.code.slice(SETTING_PREFIX.length)
    : setting.code
}

function text(value: unknown): string {
  if (typeof value === 'string') return value
  return value === undefined || value === null ? '' : String(value)
}

export function toDataPayload(
  setting: MasterSetting,
  values: MasterFormValues,
  options: { mode: 'create'; generatedCode?: string }
): MasterDataCreateBody
export function toDataPayload(
  setting: MasterSetting,
  values: MasterFormValues,
  options: { mode: 'update'; previous: MasterData }
): MasterDataUpdateBody
/**
 * v0's request bodies. Code and name come from the inputs (a generated code
 * when the code field is `auto_number`); `seq` is a number, empty → omitted
 * on create, 0 on update; the code is also written to `attributes.code` on create.
 */
export function toDataPayload(
  setting: MasterSetting,
  values: MasterFormValues,
  options:
    | { mode: 'create'; generatedCode?: string }
    | { mode: 'update'; previous: MasterData }
): MasterDataCreateBody | MasterDataUpdateBody {
  const fields = dataFields(setting)
  const hasSeq = fields.some((field) => field.physicalName === 'seq')
  const name = text(values.name)

  if (options.mode === 'update') {
    const { previous } = options
    const attributes = fromFormValues(fields, values, previous.attributes)
    const seqText = hasSeq ? text(values.seq).trim() : String(previous.seq ?? 0)
    return { name, seq: seqText === '' ? 0 : Number(seqText), attributes }
  }

  const codeField = fields.find((field) => field.physicalName === 'code')
  const generated = codeField?.dataType === 'auto_number'
  if (generated && options.generatedCode === undefined)
    throw new Error('toDataPayload: an auto_number code needs generatedCode')
  const code = generated
    ? text(options.generatedCode)
    : text(values.code).trim()
  const seqText = hasSeq ? text(values.seq).trim() : ''
  const attributes = { ...fromFormValues(fields, values), code }
  return {
    settingCode: settingCodeOf(setting),
    code,
    name,
    ...(seqText === '' ? {} : { seq: Number(seqText) }),
    attributes,
  }
}
```

```ts
import {
  isMasterFieldType,
  MASTER_FIELD_TYPES,
  type MasterFieldType,
} from './field-type-names'
import { numberOption } from './field-types'
import type { MasterField } from './types'

/** v0's three fixed fields of a new setting; they cannot be removed. */
export const defaultSettingFields: readonly MasterField[] = Object.freeze([
  {
    physicalName: 'code',
    name: 'コード',
    description: '',
    dataType: 'string',
    defaultValue: '',
    isRequired: true,
    isShowedOnList: true,
    length: '255',
  },
  {
    physicalName: 'name',
    name: '名称',
    description: '',
    dataType: 'string',
    isRequired: true,
    isShowedOnList: true,
    length: '255',
  },
  {
    physicalName: 'seq',
    name: '並び順',
    description: '',
    dataType: 'number',
    defaultValue: '',
    isRequired: false,
    isShowedOnList: true,
  },
])

export const FIXED_FIELD_NAMES: readonly string[] = Object.freeze(
  defaultSettingFields.map((field) => field.physicalName)
)

/** v0: the code field can be text, number or auto-numbered; other fields cannot be auto-numbered. */
export function allowedFieldTypes(
  physicalName: string
): readonly MasterFieldType[] {
  return physicalName === 'code'
    ? ['string', 'number', 'auto_number']
    : MASTER_FIELD_TYPES.filter((type) => type !== 'auto_number')
}

export type FieldDefinitionInput =
  | 'physicalName'
  | 'name'
  | 'dataType'
  | 'length'
  | 'min'
  | 'max'
  | 'maxRow'
  | 'defaultValue'
  | 'dataFormat'

export type FieldDefinitionError =
  | { key: 'required' }
  | { key: 'tooLong'; params: { max: number } }
  | { key: 'nameChars' }
  | { key: 'duplicate' }
  | { key: 'typeNotAllowed' }
  | { key: 'numeric' }
  | { key: 'lengthRange' }
  | { key: 'maxRowMin' }
  | { key: 'minNotLess' }
  | { key: 'maxNotGreater' }
  | { key: 'defaultRange' }
  | { key: 'defaultJson' }
  | { key: 'defaultBoolean' }
  | { key: 'defaultLength' }
  | { key: 'formatRequired' }

export type FieldDefinitionErrors = Partial<
  Record<FieldDefinitionInput, FieldDefinitionError>
>

const INTEGER = /^-?[0-9]+$/
const DIGITS = /^[0-9]+$/
const MAX_TEXT = 255

const isSet = (value: unknown) =>
  value !== undefined && value !== null && String(value).trim() !== ''

function textInput(value: string): FieldDefinitionError | undefined {
  if (value.trim() === '') return { key: 'required' }
  if (value.length > MAX_TEXT)
    return { key: 'tooLong', params: { max: MAX_TEXT } }
  return undefined
}

/**
 * v0's field-dialog rules, one error per input, plus three that v0 lacked:
 * physical names must be unique, may not contain `.`, `[` or `]` (they name
 * form inputs), and the type must be allowed for the field.
 * `siblings` are the setting's other fields (not the one being edited).
 */
export function validateFieldDefinition(
  field: MasterField,
  siblings: readonly MasterField[]
): FieldDefinitionErrors {
  const errors: FieldDefinitionErrors = {}
  const physicalName =
    textInput(field.physicalName) ??
    (/[.[\]]/.test(field.physicalName)
      ? { key: 'nameChars' as const }
      : undefined) ??
    (siblings.some((other) => other.physicalName === field.physicalName)
      ? { key: 'duplicate' as const }
      : undefined)
  if (physicalName) errors.physicalName = physicalName
  const name = textInput(field.name)
  if (name) errors.name = name

  const type = field.dataType
  if (
    !isMasterFieldType(type) ||
    !allowedFieldTypes(field.physicalName).includes(type)
  )
    errors.dataType = { key: 'typeNotAllowed' }

  if (type === 'string' && isSet(field.length)) {
    const length = String(field.length).trim()
    if (!DIGITS.test(length)) errors.length = { key: 'numeric' }
    else if (Number(length) < 1 || Number(length) > MAX_TEXT)
      errors.length = { key: 'lengthRange' }
  }

  if (type === 'number') {
    for (const input of ['min', 'max'] as const) {
      if (isSet(field[input]) && !INTEGER.test(String(field[input]).trim()))
        errors[input] = { key: 'numeric' }
    }
    const min = numberOption(field.min)
    const max = numberOption(field.max)
    if (
      !errors.min &&
      !errors.max &&
      min !== undefined &&
      max !== undefined &&
      min >= max
    ) {
      errors.min = { key: 'minNotLess' }
      errors.max = { key: 'maxNotGreater' }
    }
  }

  if (isSet(field.maxRow)) {
    const rows = String(field.maxRow).trim()
    if (!INTEGER.test(rows) || Number(rows) < 1)
      errors.maxRow = { key: 'maxRowMin' }
  }

  const fallback = field.defaultValue
  if (type === 'number' && isSet(fallback)) {
    const value = String(fallback).trim()
    const min = numberOption(field.min) ?? -Infinity
    const max = numberOption(field.max) ?? Infinity
    if (!INTEGER.test(value)) errors.defaultValue = { key: 'numeric' }
    else if (Number(value) < min || Number(value) > max)
      errors.defaultValue = { key: 'defaultRange' }
  }
  if (type === 'json' && isSet(fallback)) {
    try {
      JSON.parse(String(fallback))
    } catch {
      errors.defaultValue = { key: 'defaultJson' }
    }
  }
  if (
    type === 'boolean' &&
    fallback !== undefined &&
    fallback !== '' &&
    ![true, false, 'true', 'false'].includes(fallback as never)
  )
    errors.defaultValue = { key: 'defaultBoolean' }
  const maxLength = numberOption(field.length)
  if (
    type === 'string' &&
    typeof fallback === 'string' &&
    maxLength !== undefined &&
    fallback.length > maxLength
  )
    errors.defaultValue = { key: 'defaultLength' }

  if (
    type === 'auto_number' &&
    field.physicalName === 'code' &&
    !field.dataFormat &&
    !field.formatCode
  )
    errors.dataFormat = { key: 'formatRequired' }

  return errors
}

/**
 * What v0's dialog saved: length / pattern only on strings, min / max only on
 * numbers, a boolean default as 'true' / 'false', maxRow as a number. Every
 * other key, including unknown ones, is kept.
 */
export function normalizeFieldDefinition(field: MasterField): MasterField {
  const next: MasterField = { ...field }
  if (field.dataType !== 'string') {
    delete next.length
    delete next.pattern
  }
  if (field.dataType !== 'number') {
    delete next.min
    delete next.max
  }
  if (field.dataType === 'boolean' && typeof field.defaultValue === 'boolean')
    next.defaultValue = String(field.defaultValue)
  const rows = numberOption(field.maxRow)
  if (rows === undefined) delete next.maxRow
  else next.maxRow = rows
  return next
}
```

```ts
/** One item of `POST /api/master-bulk`; `settingCode` makes it a data record. */
export type BulkJsonItem = {
  name: string
  code: string
  attributes: Record<string, unknown>
  tenantCode?: string
  settingCode?: string
  seq?: number
}

/** v0's mapper result types: hosts map their own JSON shape with `mapRawItem`. */
export type MappedSetting = {
  kind: 'setting'
  value: {
    name: string
    code: string
    tenantCode?: string
    settingValue: Record<string, unknown>
  }
}

export type MappedData = {
  kind: 'data'
  value: {
    settingCode: string
    code: string
    name: string
    seq: number
    attributes: Record<string, unknown>
    tenantCode?: string
  }
}

export type MapResult = MappedSetting | MappedData

/** Return `null` / `undefined` to skip an entry. */
export type BulkMapper = (raw: unknown) => MapResult | null | undefined

export type BulkError =
  | { key: 'invalidJson' }
  | { key: 'notArray' }
  | { key: 'empty' }
  | { key: 'mapFailed'; index: number; message: string }
  | { key: 'invalidItem'; index: number }
  | { key: 'invalidDataItem'; index: number }
  | { key: 'invalidMappedSetting'; index: number }
  | { key: 'invalidMappedData'; index: number }
  | { key: 'settingNotAllowed'; index: number }

export type BulkParseResult = { items: BulkJsonItem[]; errors: BulkError[] }

/** The settings list imports settings and data; a setting's data list imports data only. */
export type BulkScreen = 'settings' | 'data'

function isPlainObject(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value)
}

const isText = (value: unknown): value is string => typeof value === 'string'
const isFilled = (value: unknown): value is string =>
  isText(value) && value.trim() !== ''
const optionalText = (value: unknown) => value === undefined || isText(value)

export function mapResultToBulkItem(result: MapResult): BulkJsonItem {
  if (result.kind === 'setting') {
    const { name, code, tenantCode, settingValue } = result.value
    return { name, code, tenantCode, attributes: settingValue }
  }
  const { name, code, settingCode, tenantCode, seq, attributes } = result.value
  return { name, code, settingCode, tenantCode, seq, attributes }
}

function isMappedSetting(value: MappedSetting['value']): boolean {
  return (
    isText(value.name) &&
    isText(value.code) &&
    isPlainObject(value.settingValue) &&
    optionalText(value.tenantCode)
  )
}

function isMappedData(value: MappedData['value']): boolean {
  return (
    isFilled(value.settingCode) &&
    isText(value.code) &&
    isText(value.name) &&
    typeof value.seq === 'number' &&
    isPlainObject(value.attributes) &&
    optionalText(value.tenantCode)
  )
}

function isBulkItem(entry: unknown, screen: BulkScreen): entry is BulkJsonItem {
  if (!isPlainObject(entry)) return false
  if (
    !isText(entry.code) ||
    !isText(entry.name) ||
    !isPlainObject(entry.attributes)
  )
    return false
  if (!optionalText(entry.tenantCode)) return false
  const isData = screen === 'data' || 'settingCode' in entry
  return (
    !isData || (isFilled(entry.settingCode) && typeof entry.seq === 'number')
  )
}

/**
 * v0's bulk-import checks, reported per entry instead of stopping at the
 * first one. Without a mapper each entry must already be a bulk item; with
 * one, entries mapped to `null` are skipped. `items` holds the valid entries;
 * import only when `errors` is empty.
 */
export function parseBulkJson(
  text: string,
  { screen, mapRawItem }: { screen: BulkScreen; mapRawItem?: BulkMapper }
): BulkParseResult {
  let raw: unknown
  try {
    raw = JSON.parse(text)
  } catch {
    return { items: [], errors: [{ key: 'invalidJson' }] }
  }
  if (!Array.isArray(raw)) return { items: [], errors: [{ key: 'notArray' }] }

  const items: BulkJsonItem[] = []
  const errors: BulkError[] = []
  raw.forEach((entry: unknown, index) => {
    if (!mapRawItem) {
      if (isBulkItem(entry, screen)) items.push(entry)
      else
        errors.push({
          key: screen === 'data' ? 'invalidDataItem' : 'invalidItem',
          index,
        })
      return
    }
    let mapped: MapResult | null | undefined
    try {
      mapped = mapRawItem(entry)
    } catch (error) {
      errors.push({
        key: 'mapFailed',
        index,
        message: error instanceof Error ? error.message : String(error),
      })
      return
    }
    if (!mapped) return
    if (mapped.kind === 'setting') {
      if (screen === 'data') errors.push({ key: 'settingNotAllowed', index })
      else if (!isMappedSetting(mapped.value))
        errors.push({ key: 'invalidMappedSetting', index })
      else items.push(mapResultToBulkItem(mapped))
      return
    }
    if (!isMappedData(mapped.value))
      errors.push({ key: 'invalidMappedData', index })
    else items.push(mapResultToBulkItem(mapped))
  })
  if (items.length === 0 && errors.length === 0) errors.push({ key: 'empty' })
  return { items, errors }
}

/** The starting JSON in the import dialog (v0's samples, indented for a plain text box). */
export function bulkSampleJson(

  settingCode = 'SETTING_CODE'
): string {
  const data = {

    code: 'MASTER_DATA_CODE',
    name: 'マスターデータサンプル',

    attributes:
      screen === 'data' ? { seq: 0, code: '', name: '' } : { description: '' },
  }
  if (screen === 'data') return JSON.stringify([data], null, 2)
  const field = (

  return JSON.stringify(
    [
      {
        code: 'MASTER_SETTING_CODE',
```

```ts
/** What a copy contains, in the order v0 offers it. */
export const COPY_TYPES = ['BOTH', 'SETTING_ONLY', 'DATA_ONLY'] as const
export type CopyType = (typeof COPY_TYPES)[number]

/** `POST /api/master-setting/copy` body (the backend's MasterCopyDto). */
export type MasterCopyRequest = {
  masterSettingId: string
  targetTenants: string[]
  copyType: CopyType
  dataCopyOption?: { mode: 'ALL' | 'PARTIAL'; id?: string[] }
}

/**
 * v0's request: "all tenants" sends every tenant code; data-only copies the
 * chosen records, or all of them when none is chosen.
 */
export function buildCopyRequest({
  masterSettingId,
  copyType,
  targets,
  allTenants,
  dataIds = [],
}: {
  masterSettingId: string
  copyType: CopyType
  targets: 'all' | readonly string[]
  allTenants: readonly string[]
  dataIds?: readonly string[]
}): MasterCopyRequest {
  return {
    masterSettingId,
    targetTenants: [...(targets === 'all' ? allTenants : targets)],
    copyType,
    ...(copyType === 'DATA_ONLY' && {
      dataCopyOption:
        dataIds.length > 0
          ? { mode: 'PARTIAL' as const, id: [...dataIds] }
          : { mode: 'ALL' as const },
    }),
  }
}
```

```ts
import type { BulkError } from '../core/bulk'
import type { MasterError } from '../core/errors'
import type { FieldDefinitionError } from '../core/field-definition'
import type { MasterMessages } from './master-messages'

export function formatMasterError(
  error: MasterError,
  t: MasterMessages['validation']
): string {
  switch (error.key) {
    case 'maxLength':
      return t.maxLength(error.params)
    case 'maxRows':
      return t.maxRows(error.params)
    case 'pattern':
      return t.pattern(error.params)
    case 'min':
      return t.min(error.params)
    case 'max':
      return t.max(error.params)
    default:
      return t[error.key]
  }
}

export function formatFieldDefinitionError(
  error: FieldDefinitionError,
  t: MasterMessages['fieldDefinition']
): string {
  return error.key === 'tooLong' ? t.tooLong(error.params) : t[error.key]
}

export function formatBulkError(
  error: BulkError,
  t: MasterMessages['bulk']
): string {
  const text =
    error.key === 'mapFailed'
      ? t.mapFailed({ message: error.message })
      : t[error.key]
  return 'index' in error ? `${t.item({ n: error.index + 1 })}${text}` : text
}
```
