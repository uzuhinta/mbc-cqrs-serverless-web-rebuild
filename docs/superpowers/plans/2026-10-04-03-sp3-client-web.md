# SP3 — `client-web` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@mbc-cqrs-serverless/client-web` — a dependency-free client for mbc-cqrs-serverless backends: a `fetch` HTTP client, an AppSync real-time WebSocket client, `command()` that sends a command and waits for its `command-status` without losing fast messages, and React bindings.

**Architecture:** Four small, separately tested layers. `http` (pure `fetch` wrapper with typed errors) → `realtime` (one shared WebSocket speaking AppSync's `graphql-ws` protocol, multiplexing subscriptions, keep-alive watchdog, reconnect) → `command` (subscribe-before-send + buffer, matches `requestId`) → `createMbcClient` composes them. The `/react` entry adds a provider and `useCommand`. Every external effect (`fetch`, `WebSocket`, time, randomness) is injectable, so tests use fakes instead of mocks of internals.

**Tech Stack:** SP1 toolchain only. No runtime dependencies. `react` is an optional peer (only `/react` uses it).

**Spec:** `docs/superpowers/specs/2026-10-04-survey-web-rebuild-design.md` §4. Orchestrator: `docs/superpowers/plans/2026-10-04-00-orchestrator.md`. Backend contract: `../mbc-cqrs-serverless/packages/core/src/commands/command.service.ts` (`updateStatus` publishes `{ action: 'command-status', id: requestId, tenantCode, content: { status } }`; statuses are `<step>:STARTED|FINISHED|FAILED`).

## Design decisions this plan adds to the spec

- **`MbcCommandError`** (new, spec §4.1 updated in Task 1): a `command-status` message whose status ends in `:FAILED` rejects `command()` immediately with `{ requestId, status }`. v0 waited only for `finish:FINISHED`, so a failed command hung forever.
- **getAuthToken / network failures** reject with `MbcApiError` with `status: 0` and the original error as `cause` (no response was received).
- **`command()` phases**: `options.onPhase?.('sending' | 'waiting')` lets `useCommand` report `sending` (HTTP in flight) vs `waiting` (waiting for command-status).

## Review Focus

1. **React 18 StrictMode double-mount around `useCommand`, and a component that unmounts mid-command** → the command's subscription is released, no state update happens after unmount, nothing leaks. Pinned in Task 6.
2. **`getAuthToken` rejects, or the WebSocket drops mid-`command()`** → the promise rejects with a typed error, or the client reconnects, re-subscribes, and still resolves; it never outlives `timeoutMs`. Pinned in Tasks 2, 4, 5.
3. **The `finish:FINISHED` message arrives before the HTTP response** → `command()` still resolves (buffered). Pinned in Task 5.
4. **Two concurrent `command()` calls on one client** → one socket, two subscriptions, each resolves only on its own `requestId`. Pinned in Task 5.
5. **AppSync custom domain URL (`https://api.example.com/graphql`)** → real-time URL is `wss://api.example.com/graphql/realtime` and the auth `host` is `api.example.com`. Pinned in Task 3.

```ts
export class MbcError extends Error {
  constructor(message: string, options?: { cause?: unknown }) {
    super(message, options)
    this.name = new.target.name
  }
}

/** The server answered with a non-2xx status, or no response arrived (`status: 0`). */
export class MbcApiError extends MbcError {
  readonly status: number
  readonly body: unknown

  constructor(
    status: number,
    body: unknown,
    message = `Request failed with status ${status}`,
    options?: { cause?: unknown }
  ) {
    super(message, options)
    this.status = status
    this.body = body
  }
}

export class MbcTimeoutError extends MbcError {
  readonly timeoutMs: number

  constructor(timeoutMs: number) {
    super(`Timed out after ${timeoutMs}ms`)
    this.timeoutMs = timeoutMs
  }
}

export class MbcAbortError extends MbcError {
  constructor(options?: { cause?: unknown }) {
    super('The operation was aborted', options)
  }
}

export class MbcRealtimeError extends MbcError {
  readonly errors: unknown

  constructor(
    message: string,
    options?: { cause?: unknown; errors?: unknown }
  ) {
    super(message, options)
    this.errors = options?.errors
  }
}

/** The backend reported a `<step>:FAILED` command status. */
export class MbcCommandError extends MbcError {
  readonly requestId: string
  readonly status: string

  constructor(requestId: string, status: string) {
    super(`Command ${requestId} failed (${status})`)
    this.requestId = requestId
    this.status = status
  }
}
```

```ts
import { MbcAbortError, MbcApiError, MbcTimeoutError } from './errors'

export type MaybePromise<T> = T | Promise<T>
export type QueryValue = string | number | boolean
export type QueryParams = Record<
  string,
  QueryValue | null | undefined | readonly QueryValue[]
>

export type HttpConfig = {
  apiUrl: string
  tenantCode: string | (() => string)
  getAuthToken?: () => MaybePromise<string | undefined>
  headers?: Record<string, string> | (() => Record<string, string>)
  fetch?: typeof fetch
  timeoutMs?: number
}

export type HttpMethod = 'GET' | 'POST' | 'PUT' | 'PATCH' | 'DELETE'

export type RequestOptions = {
  query?: QueryParams
  body?: unknown
  signal?: AbortSignal
  timeoutMs?: number
}

export type Http = {
  request<T>(
    method: HttpMethod,
    path: string,
    options?: RequestOptions
  ): Promise<T>
  resolveTenantCode(): string
}

const DEFAULT_TIMEOUT_MS = 30_000

export function toQueryString(query?: QueryParams): string {
  if (!query) return ''
  const params = new URLSearchParams()
  for (const [key, value] of Object.entries(query)) {
    if (value === undefined || value === null) continue
    const values = Array.isArray(value) ? value : [value]
    for (const item of values) params.append(key, String(item))
  }
  const text = params.toString()
  return text ? `?${text}` : ''
}

export function joinUrl(base: string, path: string): string {
  return `${base.replace(/\/+$/, '')}/${path.replace(/^\/+/, '')}`
}

async function readBody(response: Response): Promise<unknown> {
  if (response.status === 204) return undefined
  const text = await response.text()
  if (!text) return undefined
  const type = response.headers.get('content-type') ?? ''
  if (!type.includes('json')) return text
  try {
    return JSON.parse(text)
  } catch {
    return text
  }
}

export function createHttp(config: HttpConfig): Http {
  const resolveTenantCode = () =>
    typeof config.tenantCode === 'function'
      ? config.tenantCode()
      : config.tenantCode

  async function buildHeaders(hasBody: boolean): Promise<Headers> {
    const extra =
      typeof config.headers === 'function' ? config.headers() : config.headers
    const headers = new Headers(extra)
    headers.set('accept', 'application/json')
    if (hasBody) headers.set('content-type', 'application/json')
    headers.set('x-tenant-code', resolveTenantCode())

    let token: string | undefined
    try {
      token = await config.getAuthToken?.()
    } catch (cause) {
      throw new MbcApiError(0, undefined, 'Could not get an auth token', {
        cause,
      })
    }
    if (token) headers.set('authorization', `Bearer ${token}`)
    else headers.delete('authorization')
    return headers
  }

  async function request<T>(
    method: HttpMethod,
    path: string,
    options: RequestOptions = {}
  ): Promise<T> {
    const timeoutMs =
      options.timeoutMs ?? config.timeoutMs ?? DEFAULT_TIMEOUT_MS
    const timeout = AbortSignal.timeout(timeoutMs)
    const signal = options.signal
      ? AbortSignal.any([options.signal, timeout])
      : timeout
    const hasBody = options.body !== undefined
    const headers = await buildHeaders(hasBody)
    const doFetch = config.fetch ?? globalThis.fetch

    let response: Response
    try {
      response = await doFetch(
        joinUrl(config.apiUrl, path) + toQueryString(options.query),
        {
          method,
          headers,
          body: hasBody ? JSON.stringify(options.body) : undefined,
          signal,
        }
      )
    } catch (cause) {
      if (options.signal?.aborted) throw new MbcAbortError({ cause })
      if (timeout.aborted) throw new MbcTimeoutError(timeoutMs)
      throw new MbcApiError(0, undefined, 'Network request failed', { cause })
    }

    const body = await readBody(response)
    if (!response.ok) throw new MbcApiError(response.status, body)
    return body as T
  }

  return { request, resolveTenantCode }
}
```

```ts
import { MbcRealtimeError } from '../errors'

export type RealtimeAuth =
  { type: 'API_KEY'; apiKey: string } | { type: 'USER_POOL' }

export type GraphQLOperation = {
  query: string
  variables?: Record<string, unknown>
}

export type ServerMessage =
  | { type: 'connection_ack'; payload?: { connectionTimeoutMs?: number } }
  | { type: 'ka' }
  | { type: 'start_ack'; id: string }
  | { type: 'data'; id: string; payload: { data?: unknown } }
  | { type: 'error'; id?: string; payload?: { errors?: unknown } }
  | { type: 'complete'; id: string }
  | { type: 'connection_error'; payload?: { errors?: unknown } }

export const CONNECTION_INIT = { type: 'connection_init' } as const

export function realtimeEndpoint(httpUrl: string): {
  url: string
  host: string
} {
  const url = new URL(httpUrl)
  const host = url.host
  if (url.hostname.includes('.appsync-api.')) {
    url.hostname = url.hostname.replace(
      '.appsync-api.',
      '.appsync-realtime-api.'
    )
    url.protocol = 'wss:'
    return { url: url.toString(), host }
  }
  url.protocol = 'wss:'
  url.pathname = `${url.pathname.replace(/\/+$/, '')}/realtime`
  return { url: url.toString(), host }
}

export function authHeader(
  auth: RealtimeAuth,
  host: string,
  token: string | undefined
): Record<string, string> {
  if (auth.type === 'API_KEY') return { host, 'x-api-key': auth.apiKey }
  if (!token) {
    throw new MbcRealtimeError(
      'USER_POOL real-time auth needs getAuthToken to return a token'
    )
  }
  return { host, Authorization: token }
}

export function connectUrl(
  url: string,
  header: Record<string, string>
): string {
  const encoded = btoa(JSON.stringify(header))
  return `${url}?header=${encodeURIComponent(encoded)}&payload=e30=`
}

export function startMessage(
  id: string,
  operation: GraphQLOperation,
  header: Record<string, string>
) {
  return {
    id,
    type: 'start',
    payload: {
      data: JSON.stringify(operation),
      extensions: { authorization: header },
    },
  } as const
}

export function stopMessage(id: string) {
  return { id, type: 'stop' } as const
}

export function parseServerMessage(raw: string): ServerMessage | undefined {
  try {
    const message: unknown = JSON.parse(raw)
    if (
      typeof message === 'object' &&
      message !== null &&
      typeof (message as { type?: unknown }).type === 'string'
    ) {
      return message as ServerMessage
    }
  } catch {
    return undefined
  }
  return undefined
}
```

```ts
  }

    FakeWebSocket.instances = []
  }

  static latest(): FakeWebSocket {
    const socket = FakeWebSocket.instances.at(-1)
    if (!socket) throw new Error('no socket was opened')
    return socket
  }

  send(data: string): void {
    this.sent.push(JSON.parse(data) as Sent)
  }

  close(code = 1000, reason = ''): void {
    this.readyState = 3
    this.closedWith = { code, reason }
    this.onclose?.({ code, reason })
  }

  // ---- server side ----

  open(): void {
    this.readyState = 1
    this.onopen?.({})
  }

  receive(message: unknown): void {
    this.onmessage?.({ data: JSON.stringify(message) })
  }

  /** Opens and acknowledges the connection. */
  accept(connectionTimeoutMs = 300_000): void {
    this.open()
    this.receive({ type: 'connection_ack', payload: { connectionTimeoutMs } })
  }

  starts(): Sent[] {
    return this.sent.filter((message) => message.type === 'start')
  }

  ackAll(): void {
    for (const start of this.starts())
      this.receive({ type: 'start_ack', id: start.id })
  }

  drop(): void {
    this.readyState = 3
    this.onclose?.({ code: 1006, reason: 'dropped' })
  }
}
```

```ts
import { MbcRealtimeError } from '../errors'
import type { MaybePromise } from '../http'
import {
  authHeader,
  CONNECTION_INIT,
  connectUrl,
  parseServerMessage,
  realtimeEndpoint,
  startMessage,
  stopMessage,
  type GraphQLOperation,
  type RealtimeAuth,
  type ServerMessage,
} from './protocol'

export type WebSocketLike = {
  readyState: number
  send(data: string): void
  close(code?: number, reason?: string): void
  onopen: ((event: unknown) => void) | null
  onmessage: ((event: { data: unknown }) => void) | null
  onclose: ((event: { code: number; reason: string }) => void) | null
  onerror: ((event: unknown) => void) | null
}

export type WebSocketConstructor = new (
  url: string,
  protocols?: string | string[]
) => WebSocketLike

export type RealtimeOptions = {
  url: string
  auth: RealtimeAuth
  getAuthToken?: () => MaybePromise<string | undefined>
  WebSocket?: WebSocketConstructor
  reconnect?: { initialDelayMs?: number; maxDelayMs?: number }
  random?: () => number
}

export type SubscriptionHandlers = {
  next: (data: unknown) => void
  error?: (error: MbcRealtimeError) => void
}

export type Subscription = { ready: Promise<void>; unsubscribe(): void }

export type RealtimeClient = {
  subscribe(
    operation: GraphQLOperation,
    handlers: SubscriptionHandlers
  ): Subscription
  close(): void
}

type Entry = {
  operation: GraphQLOperation
  handlers: SubscriptionHandlers
  resolveReady: () => void
  rejectReady: (error: MbcRealtimeError) => void
  settled: boolean
}

const OPEN = 1
const DEFAULT_CONNECTION_TIMEOUT_MS = 300_000
const KEEP_ALIVE_TIMEOUT_CODE = 4000

export function createRealtimeClient(options: RealtimeOptions): RealtimeClient {
  const endpoint = realtimeEndpoint(options.url)
  const initialDelayMs = options.reconnect?.initialDelayMs ?? 1_000
  const maxDelayMs = options.reconnect?.maxDelayMs ?? 30_000
  const random = options.random ?? Math.random
  const entries = new Map<string, Entry>()

  let nextId = 0
  let socket: WebSocketLike | undefined
  let header: Record<string, string> | undefined
  let acknowledged = false
  let connecting = false
  let attempt = 0
  let keepAliveTimer: ReturnType<typeof setTimeout> | undefined
  let reconnectTimer: ReturnType<typeof setTimeout> | undefined
  let keepAliveMs = DEFAULT_CONNECTION_TIMEOUT_MS

  function settle(entry: Entry, error?: MbcRealtimeError): void {
    if (entry.settled) return
    entry.settled = true
    if (error) entry.rejectReady(error)
    else entry.resolveReady()
  }

  function fail(id: string, error: MbcRealtimeError): void {
    const entry = entries.get(id)
    if (!entry) return
    entries.delete(id)
    settle(entry, error)
    entry.handlers.error?.(error)
  }

  function failAll(error: MbcRealtimeError): void {
    for (const id of [...entries.keys()]) fail(id, error)
  }

  function clearTimers(): void {
    clearTimeout(keepAliveTimer)
    clearTimeout(reconnectTimer)
    keepAliveTimer = undefined
    reconnectTimer = undefined
  }

  function armKeepAlive(): void {
    clearTimeout(keepAliveTimer)
    keepAliveTimer = setTimeout(() => {
      socket?.close(KEEP_ALIVE_TIMEOUT_CODE, 'keep-alive timeout')
    }, keepAliveMs)
  }

  function send(message: unknown): void {
    if (socket?.readyState === OPEN) socket.send(JSON.stringify(message))
  }

  function sendStart(id: string, entry: Entry): void {
    if (header) send(startMessage(id, entry.operation, header))
  }

  function handle(message: ServerMessage): void {
    switch (message.type) {
      case 'connection_ack':
        acknowledged = true
        attempt = 0
        keepAliveMs =
          message.payload?.connectionTimeoutMs ?? DEFAULT_CONNECTION_TIMEOUT_MS
        armKeepAlive()
        for (const [id, entry] of entries) sendStart(id, entry)
        return
      case 'ka':
        armKeepAlive()
        return
      case 'start_ack': {
        const entry = entries.get(message.id)
        if (entry) settle(entry)
        return
      }
      case 'data':
        entries.get(message.id)?.handlers.next(message.payload.data)
        return
      case 'error':
        if (message.id) {
          fail(
            message.id,
            new MbcRealtimeError('Subscription failed', {
              errors: message.payload?.errors,
            })
          )
        }
        return
      case 'complete':
        entries.delete(message.id)
        return
      case 'connection_error': {
        const error = new MbcRealtimeError(
          'Real-time connection was rejected',
          {
            errors: message.payload?.errors,
          }
        )
        failAll(error)
        shutdown()
        return
      }
    }
  }

  function scheduleReconnect(): void {
    if (entries.size === 0 || reconnectTimer) return
    const delay =
      Math.min(maxDelayMs, initialDelayMs * 2 ** attempt) * (0.5 + random() / 2)
    attempt += 1
    reconnectTimer = setTimeout(() => {
      reconnectTimer = undefined
      void connect()
    }, delay)
  }

  async function connect(): Promise<void> {
    if (socket || connecting || entries.size === 0) return
    connecting = true
    let token: string | undefined
    try {
      token =
        options.auth.type === 'USER_POOL'
          ? await options.getAuthToken?.()
          : undefined
      header = authHeader(options.auth, endpoint.host, token)
    } catch (cause) {
      connecting = false
      failAll(
        cause instanceof MbcRealtimeError
          ? cause
          : new MbcRealtimeError('Could not get a real-time auth token', {
              cause,
            })
      )
      return
    }
    connecting = false
    if (entries.size === 0) return

    const Ctor =
      options.WebSocket ??
      (globalThis.WebSocket as unknown as WebSocketConstructor)
    const ws = new Ctor(connectUrl(endpoint.url, header), ['graphql-ws'])
    socket = ws
    acknowledged = false
    ws.onopen = () => send(CONNECTION_INIT)
    ws.onmessage = (event) => {
      if (typeof event.data !== 'string') return
      const message = parseServerMessage(event.data)
      if (message) handle(message)
    }
    ws.onerror = () => {}
    ws.onclose = () => {
      if (socket !== ws) return
      socket = undefined
      acknowledged = false
      clearTimeout(keepAliveTimer)
      scheduleReconnect()
    }
  }

  function shutdown(): void {
    clearTimers()
    const ws = socket
    socket = undefined
    acknowledged = false
    if (ws && ws.readyState <= OPEN) ws.close(1000, 'done')
  }

  function subscribe(
    operation: GraphQLOperation,
    handlers: SubscriptionHandlers
  ): Subscription {
    const id = String((nextId += 1))
    let resolveReady!: () => void
    let rejectReady!: (error: MbcRealtimeError) => void
    const ready = new Promise<void>((resolve, reject) => {
      resolveReady = resolve
      rejectReady = reject
    })
    // Callers that never await `ready` must not see an unhandled rejection.
    ready.catch(() => {})
    const entry: Entry = {
      operation,
      handlers,
      resolveReady,
      rejectReady,
      settled: false,
    }
    entries.set(id, entry)

    if (socket && acknowledged) sendStart(id, entry)
    else void connect()

    return {
      ready,
      unsubscribe() {
        if (!entries.delete(id)) return
        settle(
          entry,
          new MbcRealtimeError('Unsubscribed before the subscription started')
        )
        send(stopMessage(id))
        if (entries.size === 0) shutdown()
      },
    }
  }

  return {
    subscribe,
    close() {
      for (const id of [...entries.keys()]) entries.delete(id)
      shutdown()
    },
  }
}
```

```ts
  const message = (data as { onMessage?: unknown } | null)?.onMessage
```

```ts
import {
  MbcAbortError,
  MbcApiError,
  MbcCommandError,
  MbcTimeoutError,
} from './errors'
import type { Http, QueryParams } from './http'
import { ON_MESSAGE, parseMessage, type MbcMessage } from './messages'
import type { RealtimeClient } from './realtime/client'

export type CommandRequest = {
  method: 'POST' | 'PUT' | 'PATCH' | 'DELETE'
  path: string
  body?: unknown
  query?: QueryParams
}

export type CommandOptions = {
  timeoutMs?: number
  signal?: AbortSignal
  onPhase?: (phase: 'sending' | 'waiting') => void
}

export type CommandResult<T> = { data: T; requestId: string }

const DEFAULT_TIMEOUT_MS = 60_000
const FINISHED = 'finish:FINISHED'

function statusOf(message: MbcMessage): string | undefined {
  const content = message.content as { status?: unknown } | null
  return typeof content?.status === 'string' ? content.status : undefined
}

export function createCommand(
  http: Http,
  realtime: RealtimeClient | undefined
) {
  return async function command<T extends { requestId?: string }>(
    request: CommandRequest,
    options: CommandOptions = {}
  ): Promise<CommandResult<T>> {
    const timeoutMs = options.timeoutMs ?? DEFAULT_TIMEOUT_MS
    const controller = new AbortController()
    const cleanups: (() => void)[] = []

    const outcome = new Promise<CommandResult<T>>((resolve, reject) => {
      const timer = setTimeout(() => {
        reject(new MbcTimeoutError(timeoutMs))
      }, timeoutMs)
      cleanups.push(() => clearTimeout(timer))

      const onAbort = () =>
        reject(new MbcAbortError({ cause: options.signal?.reason }))
      if (options.signal?.aborted) onAbort()
      options.signal?.addEventListener('abort', onAbort, { once: true })
      cleanups.push(() => options.signal?.removeEventListener('abort', onAbort))

      void (async () => {
        const buffered: MbcMessage[] = []
        let requestId: string | undefined
        let data: T | undefined

        const check = (message: MbcMessage) => {
          if (requestId === undefined || message.id !== requestId) return
          const status = statusOf(message)
          if (status === FINISHED) resolve({ data: data as T, requestId })
          else if (status?.endsWith(':FAILED'))
            reject(new MbcCommandError(requestId, status))
        }

        if (realtime) {
          const subscription = realtime.subscribe(
            {
              query: ON_MESSAGE,
              variables: {
                tenantCode: http.resolveTenantCode(),
                action: 'command-status',
              },
            },
            {
              next: (payload) => {
                const message = parseMessage(payload)
                if (!message) return
                if (requestId === undefined) buffered.push(message)
                else check(message)
              },
              error: (error) => reject(error),
            }
          )
          cleanups.push(() => subscription.unsubscribe())
          await subscription.ready
        }

        options.onPhase?.('sending')
        data = await http.request<T>(request.method, request.path, {
          body: request.body,
          query: request.query,
          signal: controller.signal,
        })
        if (!data?.requestId) {
          throw new MbcApiError(
            200,
            data,
            'The command response has no requestId'
          )
        }
        requestId = data.requestId
        if (!realtime) {
          resolve({ data, requestId })
          return
        }
        options.onPhase?.('waiting')
        for (const message of buffered.splice(0)) check(message)
      })().catch(reject)
    })

    try {
      return await outcome
    } finally {
      controller.abort()
      for (const cleanup of cleanups) cleanup()
    }
  }
}
```

```ts
import {
  createCommand,
  type CommandOptions,
  type CommandRequest,
  type CommandResult,
} from './command'
import type { MbcRealtimeError } from './errors'
import { createHttp, type HttpConfig, type RequestOptions } from './http'
import {
  ON_MESSAGE,
  parseMessage,
  type MbcMessage,
  type MessageFilter,
} from './messages'
import {
  createRealtimeClient,
  type Subscription,
  type WebSocketConstructor,
} from './realtime/client'
import type { RealtimeAuth } from './realtime/protocol'

export type MbcClientConfig = HttpConfig & {
  realtime?: {
    url: string
    auth: RealtimeAuth
    WebSocket?: WebSocketConstructor
  }
}

type VerbOptions = Omit<RequestOptions, 'body'>

export type MbcClient = {
  get<T>(path: string, options?: VerbOptions): Promise<T>
  post<T>(path: string, body?: unknown, options?: VerbOptions): Promise<T>
  put<T>(path: string, body?: unknown, options?: VerbOptions): Promise<T>
  patch<T>(path: string, body?: unknown, options?: VerbOptions): Promise<T>
  delete<T>(path: string, options?: VerbOptions): Promise<T>
  command<T extends { requestId?: string }>(
    request: CommandRequest,
    options?: CommandOptions
  ): Promise<CommandResult<T>>
  messages:
    | {
        subscribe(
          filter: MessageFilter,
          onMessage: (message: MbcMessage) => void,
          onError?: (error: MbcRealtimeError) => void
        ): Subscription
      }
    | undefined
  tenantCode(): string
  close(): void
}

export function createMbcClient(config: MbcClientConfig): MbcClient {
  const http = createHttp(config)
  const realtime = config.realtime
    ? createRealtimeClient({
        ...config.realtime,
        getAuthToken: config.getAuthToken,
      })
    : undefined

  return {
    get: (path, options) => http.request('GET', path, options),
    post: (path, body, options) =>
      http.request('POST', path, { ...options, body }),
    put: (path, body, options) =>
      http.request('PUT', path, { ...options, body }),
    patch: (path, body, options) =>
      http.request('PATCH', path, { ...options, body }),
    delete: (path, options) => http.request('DELETE', path, options),
    command: createCommand(http, realtime),
    messages: realtime && {
      subscribe(filter, onMessage, onError) {
        return realtime.subscribe(
          { query: ON_MESSAGE, variables: filter },
          {
            next: (payload) => {
              const message = parseMessage(payload)
              if (message) onMessage(message)
            },
            error: onError,
          }
        )
      },
    },
    tenantCode: http.resolveTenantCode,
    close: () => realtime?.close(),
  }
}
```

```ts
'use client'

import { useCallback, useEffect, useRef, useState } from 'react'

import type { MbcClient } from '../client'
import { useMbcClient } from './provider'

export type CommandStatus = 'idle' | 'sending' | 'waiting' | 'done' | 'error'

export type CommandContext = {
  client: MbcClient
  signal: AbortSignal
  onPhase: (phase: 'sending' | 'waiting') => void
}

type State<R> = { status: CommandStatus; data: R | undefined; error: unknown }

const IDLE = { status: 'idle', data: undefined, error: undefined } as const

export function useCommand<A extends unknown[], R>(
  fn: (context: CommandContext, ...args: A) => Promise<R>
) {
  const client = useMbcClient()
  const [state, setState] = useState<State<R>>(IDLE)
  const fnRef = useRef(fn)
  const controllerRef = useRef<AbortController | null>(null)
  const mountedRef = useRef(false)

  useEffect(() => {
    fnRef.current = fn
  })

  useEffect(() => {
    mountedRef.current = true
    return () => {
      mountedRef.current = false
      controllerRef.current?.abort()
    }
  }, [])

  const run = useCallback(
    async (...args: A): Promise<R | undefined> => {
      controllerRef.current?.abort()
      const controller = new AbortController()
      controllerRef.current = controller
      const update = (next: State<R>) => {
        if (mountedRef.current && controllerRef.current === controller)
          setState(next)
      }

      update({ status: 'sending', data: undefined, error: undefined })
      try {
        const data = await fnRef.current(
          {
            client,
            signal: controller.signal,
            onPhase: (phase) =>
              update({ status: phase, data: undefined, error: undefined }),
          },
          ...args
        )
        if (controller.signal.aborted) return undefined
        update({ status: 'done', data, error: undefined })
        return data
      } catch (error) {
        if (controller.signal.aborted) return undefined
        update({ status: 'error', data: undefined, error })
        return undefined
      }
    },
    [client]
  )

  const reset = useCallback(() => {
    controllerRef.current?.abort()
    controllerRef.current = null
    setState(IDLE)
  }, [])

  return { ...state, run, reset }
}
```
