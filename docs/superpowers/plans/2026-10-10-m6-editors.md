# M6 — Rich Editors (`/editors`) Implementation Plan

> **For agentic workers:** Implement this plan task by task, in order. Every task is test-first: write the test, run it and watch it fail for the stated reason, write the code, run it and watch it pass, commit. If your harness has the superpowers skills, use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship master-web's opt-in `/editors` entry. It provides three editors, each loading its library after mount, and `editorRenderers`, which plugs them into the data editor. It also ships `editors.css`, the libraries' styles scoped to their own classes.

| Editor           | Library                 |
| ---------------- | ----------------------- |
| `RichTextEditor` | react-quill-new (Quill) |
| `MarkdownEditor` | `@uiw/react-md-editor`  |
| `JsonEditor`     | `jsoneditor`            |

**Architecture:**

- **Optional peers.** The three libraries are optional peer dependencies. Only files under `packages/master-web/src/editors/` load them, and only through `import()`; M1's lint rules already enforce this.
- **Loading.** Each editor shows a plain text box on the server and until its library arrives, then swaps it for the real editor. It reports only the user's edits.
- **Labels.** Each editor labels the library's own input, and labels it again when the library rebuilds it.
- **`editors.css`.** A build script (`scripts/build-editors-css.ts`) builds it from Quill's and jsoneditor's CSS and copies jsoneditor's icon sprite beside it. The Markdown editor imports its own, already scoped CSS.
- **Focus.** The data editor now focuses an invalid field's control by its id, because a rich editor's editing area is not an input.

**Tech Stack:** TypeScript ~6.0, React 18/19, react-quill-new 3.8 (Quill 2) with quill-delta 5, `@uiw/react-md-editor` 4.1, jsoneditor 10.4 (Ace), postcss, Vitest + jsdom + Testing Library, pnpm 10 workspace, Node 24.13 via fnm.

**Spec:** `docs/superpowers/specs/2026-10-06-master-web-rebuild-design.md` §2 (optional peers), §3.3 (`/editors`), §4 (accessibility, SSR). Orchestrator: `docs/superpowers/plans/2026-10-06-m0-master-orchestrator.md`, sub-plan M6.

## Review Focus

Each item is pinned by a test in the task that owns it:

1. **Server rendering.** The editors render a plain text box on the server (no `window`, no library) and load after mount. The Next app builds with `/editors` imported. _Task 3: "render a plain text box on the server, and load the editor after mount"; Task 5: the smoke build._
2. **Loading an editor changes nothing.** Quill turns plain text into a paragraph without reporting it, and jsoneditor's `setText` is not reported. A record saved after an unrelated edit keeps its HTML, Markdown and JSON exactly. _Task 3: "report only the user's edits: loading the editor changes nothing", "plug into the data editor; untouched fields save unchanged"._
3. **Labels survive the library rebuilding its element.** Under StrictMode, react-quill-new builds its editing area again, and Ace builds a new input on a mode change. _Task 3: "keep the label when the library rebuilds its element (StrictMode mounts twice)"._
4. **`editors.css` stays scoped.** It has only the libraries' own selectors and none of `:root`, `html` or `body`, and its icon sprite ships beside it. _Task 1: the `scopeEditorCss` tests; Task 4: "scopes editors.css to the editors' own classes, its files beside it"._
5. **The optional libraries stay optional.** Only `editors/` loads them, with `import()`, and the root and `/core` entries never reach `editors/`. _Task 4: "loads the optional editors only with import() from editors/", "keeps the root and /core entries free of the editors"._

## Rulings already made (do not undo)

- **`@uiw/react-md-editor`'s CSS is not in `editors.css`.** Its JavaScript imports its own CSS, which is already scoped to `.w-md-editor` and `.wmde-markdown`. Task 5 updates the spec.
- **jsoneditor's icon sprite is copied, not inlined.** It is copied to `dist/editors-assets/` and its `url()` rewritten there. Inlining repeated the 31 KB sprite for every `url()`, making `editors.css` 518 KB instead of 57 KB.
- **No global Quill registration.** v0 registered Quill's block as `<div>` globally, which would change a host's own Quill. New HTML uses `<p>`, and Quill reads v0's `<div>` HTML fine.
- **No colour mapping.** The libraries use fixed colours, not variables, so nothing maps to ui-web tokens. The Markdown editor stays light (`data-color-mode="light"`).
- **jsoneditor modes:** code mode (v0) when editing, and the read-only tree view when disabled. Text that is not JSON has no tree view, so it stays in code mode.
- **Quill's toolbar is hidden when disabled** (v0 hid it with a class) through `mbc:[&_.ql-toolbar]:hidden`, so ui-web's style test allows `ql-toolbar` in master-web's `styles.css`.
- **Labels are re-applied by a `MutationObserver` (`useAttributes`).** The libraries replace their elements at times React does not see.
- **`quill-delta` is an optional peer too,** because react-quill-new declares it as a peer.
- **The data editor focuses an invalid field's control by its id** (the renderer contract's `id`), falling back to the field's first input. Quill's editing area is not an input, and its toolbar buttons come first.

```ts
import { copyFileSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs'
import { createRequire } from 'node:module'
import { basename, dirname, resolve } from 'node:path'
import { fileURLToPath } from 'node:url'

import postcss, { type AtRule } from 'postcss'

/** A library stylesheet and the class fragment every kept selector must contain. */
export type EditorStylesheet = { file: string; marker: string }

/**
 * The stylesheets `editors.css` is built from. `@uiw/react-md-editor` is not
 * here: its JavaScript imports its own CSS, which is already scoped.
 */
export const EDITOR_STYLESHEETS: readonly EditorStylesheet[] = [
  { file: 'react-quill-new/dist/quill.snow.css', marker: 'ql-' },
  { file: 'jsoneditor/dist/jsoneditor.css', marker: 'jsoneditor' },
]

const GLOBAL_SELECTOR = /(^|[\s>+~(,])(:root|html|body)(?![\w-])/
const KEYFRAMES = /keyframes$/

function isKeyframe(node: { parent?: unknown }): boolean {
  const parent = node.parent as AtRule | undefined
  return parent?.type === 'atrule' && KEYFRAMES.test(parent.name)
}

/**
 * Keeps only selectors that contain the library's `marker` and none of
 * `:root`, `html` or `body`; drops at-rules left empty and keyframes no kept
 * rule uses. `rewriteUrl` gives the new address of a file the CSS points at.
 */
export function scopeEditorCss(
  css: string,
  marker: string,
  rewriteUrl?: (url: string) => string
): string {
  const root = postcss.parse(css)
  root.walkRules((rule) => {
    if (isKeyframe(rule)) return
    const kept = rule.selectors.filter(
      (selector) => selector.includes(marker) && !GLOBAL_SELECTOR.test(selector)
    )
    if (kept.length === 0) rule.remove()
    else rule.selectors = kept
  })

  const used = new Set<string>()
  root.walkDecls(/^(-\w+-)?animation(-name)?$/, (decl) => {
    for (const word of decl.value.split(/[\s,]+/)) used.add(word)
  })
  root.walkAtRules(KEYFRAMES, (atRule) => {
    if (!used.has(atRule.params.trim())) atRule.remove()
  })

  // Emptied blocks may sit inside other blocks: repeat until none is left.
  for (let removed = true; removed;) {
    removed = false
    root.walkAtRules((atRule) => {
      if (atRule.nodes && atRule.nodes.length === 0) {
        atRule.remove()
        removed = true
      }
    })
  }

  if (rewriteUrl)
    root.walkDecls((decl) => {
      decl.value = decl.value.replace(
        /url\((['"]?)([^'")]+)\1\)/g,
        (match, _quote: string, url: string) =>
          url.startsWith('data:') ? match : `url("${rewriteUrl(url)}")`
      )
    })
  return root.toString()
}

const ASSETS = 'editors-assets'

function main(): void {
  const resolveFrom = createRequire(resolve('package.json'))
  mkdirSync(`dist/${ASSETS}`, { recursive: true })
  const parts = EDITOR_STYLESHEETS.map(({ file, marker }) => {
    const path = resolveFrom.resolve(file)
    // Files the CSS points at (jsoneditor's icon sprite) are copied next to
    // editors.css; the host's bundler emits them like any CSS asset.
    return scopeEditorCss(readFileSync(path, 'utf8'), marker, (url) => {
      const name = basename(url)
      copyFileSync(resolve(dirname(path), url), `dist/${ASSETS}/${name}`)
      return `./${ASSETS}/${name}`
    })
  })
  writeFileSync(
    'dist/editors.css',
    `/* Rich editors' styles for @mbc-cqrs-serverless/master-web/editors: ${EDITOR_STYLESHEETS.map((sheet) => sheet.file).join(', ')}, scoped to their own classes. */\n${parts.join('\n')}`
  )
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  main()
}
```

```ts
'use client'

import { useEffect, useState, type RefObject } from 'react'

/**
 * A module loaded after mount: `undefined` on the server, until it arrives,
 * and if loading fails (the caller keeps showing its fallback).
 */
export function useLibrary<T>(load: () => Promise<T>): T | undefined {
  const [loaded, setLoaded] = useState<{ module: T }>()
  useEffect(() => {
    let live = true
    load().then(
      (module) => {
        if (live) setLoaded({ module })
      },
      () => {}
    )
    return () => {
      live = false
    }
  }, [load])
  return loaded?.module
}

/**
 * Keeps attributes on the element `selector` finds inside `container`. A
 * library may replace that element at any time (Quill rebuilds its editing
 * area, Ace its input on a mode change), so they are applied again whenever
 * the container's content changes. `undefined` removes an attribute.
 */
export function useAttributes(
  container: RefObject<HTMLElement | null>,
  selector: string,
  attributes: Readonly<Record<string, string | undefined>>
) {
  const key = JSON.stringify(
    Object.entries(attributes).map(([name, value]) => [name, value ?? null])
  )
  useEffect(() => {
    const root = container.current
    if (!root) return
    const wanted = JSON.parse(key) as [string, string | null][]
    const apply = () => {
      const element = root.querySelector(selector)
      if (!element) return
      for (const [name, value] of wanted) {
        if (element.getAttribute(name) === value) continue
        if (value === null) element.removeAttribute(name)
        else element.setAttribute(name, value)
      }
    }
    apply()
    const observer = new MutationObserver(apply)
    observer.observe(root, { childList: true, subtree: true })
    return () => observer.disconnect()
  })
}
```

```tsx
'use client'

import { useEffect, useRef } from 'react'

import { EditorFallback } from './editor-fallback'
import type { EditorProps } from './types'
import { useAttributes, useLibrary } from './use-library'

const loadJsonEditor = () => import('jsoneditor')

type JsonEditorModule = Awaited<ReturnType<typeof loadJsonEditor>>
type JsonEditorInstance = InstanceType<JsonEditorModule['default']>

/** jsoneditor's class, whether the bundler hands the UMD build over as `default` or as the module. */
function editorClass(module: JsonEditorModule): JsonEditorModule['default'] {
  return (
    (module as { default?: JsonEditorModule['default'] }).default ??
    (module as unknown as JsonEditorModule['default'])
  )
}

const isJson = (text: string) => {
  try {
    JSON.parse(text)
    return true
  } catch {
    return false
  }
}

/**
 * Disabled JSON gets the read-only tree view; text that is not JSON has no
 * tree, so it stays in code mode, read-only.
 */
function show(instance: JsonEditorInstance, text: string, disabled: boolean) {
  const mode = disabled && isJson(text) ? 'view' : 'code'
  if (instance.getMode() !== mode) instance.setMode(mode)
  if (mode === 'code')
    (instance.aceEditor as typeof instance.aceEditor | undefined)?.setReadOnly(
      disabled
    )
}

/** JSON in jsoneditor's code mode (v0); its read-only tree view when disabled. */
export function JsonEditor(props: EditorProps) {
  const { value, onChange, disabled = false } = props
  const { id, labelId, describedBy, invalid } = props
  const library = useLibrary(loadJsonEditor)
  const container = useRef<HTMLDivElement>(null)
  const editor = useRef<JsonEditorInstance | null>(null)
  const latest = useRef({ value, onChange, disabled })
  useEffect(() => {
    latest.current = { value, onChange, disabled }
  })

  useEffect(() => {
    const element = container.current
    if (!library || !element) return
    const Editor = editorClass(library)
    const instance = new Editor(element, {
      mode: 'code',
      enableSort: false,
      enableTransform: false,
      // The user's edits only: setText does not call it.
      onChangeText: (text: string) => latest.current.onChange(text),
      // jsoneditor's default is window.alert; its code mode marks errors itself.
      onError: () => {},
    })
    instance.setText(latest.current.value)
    show(instance, latest.current.value, latest.current.disabled)
    editor.current = instance
    return () => {
      instance.destroy()
      editor.current = null
    }
  }, [library])

  useEffect(() => {
    const instance = editor.current
    if (instance && instance.getText() !== value) instance.setText(value)
  }, [value])

  useEffect(() => {
    const instance = editor.current
    if (instance) show(instance, instance.getText(), disabled)
  }, [disabled])

  // Ace's input is created again on every mode change.
  useAttributes(container, 'textarea.ace_text-input', {
    id,
    'aria-labelledby': labelId,
    'aria-describedby': describedBy,
    'aria-invalid': invalid ? 'true' : undefined,
  })

  if (!library) return <EditorFallback {...props} />
  return (
    <div
      ref={container}
      data-mbc-editor="json"
      role="group"
      aria-labelledby={labelId}
      className="mbc:h-[500px]"
    />
  )
}
```

```tsx
  rows: T[],
  sort: ListSort | undefined,
  value: (row: T, column: string) => string | number
) {
  if (!sort) return rows
  return [...rows].sort((a, b) => {
    const x = value(a, sort.column)
    const y = value(b, sort.column)
    const order = x < y ? -1 : x > y ? 1 : 0
    return sort.desc ? -order : order
  })
}
```
