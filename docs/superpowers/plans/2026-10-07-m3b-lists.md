**Goal:** Build master-web's two list screens, `MasterSettingList` and `MasterDataList`, on M3a's parts. Also fix what a visual probe of those parts found: pagination labels breaking one character per line, low header contrast, columns squeezed on phones, and the JSON dialog growing past the screen.

**Architecture:** Both screens are prop-driven: the host passes rows, the total and the list state (`page`, `pageSize`, filters, `sort`) and gets the next state back from `onStateChange`. M8's `/mbc` pages will fetch and own that state. `/core` gains the list state and row types. A shared `list/` folder holds the error alert and the search-draft hook. `data/DataCell` formats a value by field type. ui-web gains the `--mbc-emphasis` colour (master v0's dark section headers). Text comes from two new namespaces, `masterSetting` and `masterData`.

**Tech Stack:** TypeScript ~6.0 (`strict`, `noUncheckedIndexedAccess`), React 18/19, ui-web primitives (Radix), lucide-react 1.52, Tailwind v4 with the `mbc:` prefix, Vitest + jsdom + Testing Library + axe-core, pnpm 10 workspace, Node 24.13 via fnm.

## Review Focus

Each item is pinned by a test in the task that owns it:

1. **A date stored with a time and an offset** (`2026-10-07T23:30:00-05:00`) shows the calendar date as written (2026年10月07日). 2. **Filters that change from outside** (the host restores them from the URL on Back) are followed by the search inputs, and typing continues from the new values. _Task 5: "follows filters that change from outside, then keeps typing from them"._
3. **Setting codes and ids with `#`** link to the data list with the decoded id (`settingId: row.id`) and show the code without its `MASTER_SETTING#` prefix. _Task 5: "lists settings with their own code linking to the data list"._
4. **A setting with no `code` or `name` field** still gets code and name columns, so every row can be opened (v0). _Task 6: "adds code and name columns when the setting has no such fields (v0)"._
5. **A failed load** shows an alert with a reload button above the table, and the rest of the screen stays usable. _Task 5: "says when loading failed and offers a reload"; Task 6: "says when loading failed"._

## Rulings already made (do not undo)

- **No "own tenant" column** on the settings list: v0's live list had none (it lived in an unused table component). Task 7 updates the spec.
- **Search applies on submit** (the Search button or Enter), and the page goes back to 1 on search, clear, page-size change and sort (v0). The typed draft lives in the screen; the applied filters live in `state`.
- **State belongs to the host:** the screens take `state` and call `onStateChange` with the next one. `initialSettingListState()` / `initialDataListState()` give v0's start: page 1, 20 rows, empty filters, deleted rows hidden.
- **Dates show the calendar date as stored** (the `YYYY-MM-DD` the value starts with), in the locale's form (`2026年10月07日` / `2026-10-07`). They are never converted to the viewer's time zone. Values that don't start with a date show as written.
- **Data list columns:** fields with `isShowedOnList`, in setting order. `code` links to the record and shows `masterCode` (then `code`). `name` and `seq` sort. A setting without a shown `code` field gets a code column first, plus a name column unless a `name` field is shown (v0).
- **Section headers use `--mbc-emphasis`,** a new ui-web colour (master v0's dark navy, with a light text colour), so hosts theme it in one place. ui-web's `Accordion` provides the sections; only the header colours and spacing are master-web's.
- **Fixes from the visual probe of M3a's parts** (Task 1 and Task 3):
  - pagination labels stay on one line, and the page-number box no longer takes the row;
  - the page-size select sizes to its text instead of cutting "20 / ページ";
  - table headers use the text colour (muted text on the muted header measured 4.34:1);
  - a table keeps 6.5rem per column and scrolls sideways below that;
  - the JSON dialog keeps its buttons on screen.

```tsx
'use client'

import { useState, type KeyboardEvent, type MouseEvent } from 'react'

import { useMessages } from '../i18n/provider'
import { uiMessages } from '../i18n/ui-messages'
import { cn } from '../lib/cn'
import { getPaginationItems } from '../lib/pagination-items'
import { Input } from './input'
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from './pagination'
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from './select'

// Labels keep their width; CJK text would otherwise break after every character.
const LABEL = 'mbc:shrink-0 mbc:whitespace-nowrap mbc:text-muted-foreground'

const ARROW =
  'mbc:flex mbc:h-8 mbc:w-8 mbc:items-center mbc:justify-center mbc:aria-disabled:pointer-events-none mbc:aria-disabled:cursor-not-allowed mbc:aria-disabled:text-[#A3ACBA] mbc:aria-disabled:opacity-50'

export type PaginationBarProps = {
  /** 1-based. */
  page: number
  pageSize: number
  total: number
  onPageChange: (page: number) => void
  onPageSizeChange?: (pageSize: number) => void
  pageSizeOptions?: readonly number[]
  /**
   * `table`: a data table's bar (master v0) — the result count first, the
   * page size after the pages, a page-number box, and shown even with one
   * page or no rows. `default`: survey v0's bar, hidden with one page.
   */
  variant?: 'default' | 'table'
  /** Accessible name; give each bar its own when a page has two. Default: the `ui` pagination label. */
  label?: string
  className?: string
}

function JumpToPage({
  lastPage,
  onPageChange,
}: {
  lastPage: number
  onPageChange: (page: number) => void
}) {
  const t = useMessages(uiMessages)
  const [value, setValue] = useState('')
  const onKeyDown = (event: KeyboardEvent<HTMLInputElement>) => {
    if (event.key !== 'Enter') return
    event.preventDefault()
    const target = Number(value)
    if (Number.isInteger(target) && target >= 1 && target <= lastPage)
      onPageChange(target)
    setValue('')
  }
  return (
    <span data-part="jump" className="mbc:flex mbc:items-center mbc:gap-2">
      {t.pagination.jumpBefore && (
        <span aria-hidden className={LABEL}>
          {t.pagination.jumpBefore}
        </span>
      )}
      {/* Input's wrapper is w-full: bound it, or it takes the row. */}
      <span data-part="page-box" className="mbc:w-16 mbc:shrink-0">
        <Input
          type="number"
          inputMode="numeric"
          min={1}
          max={lastPage}
          value={value}
          onChange={(event) => setValue(event.target.value)}
          onKeyDown={onKeyDown}
          aria-label={t.pagination.jump({ last: lastPage })}
          className="mbc:h-8 mbc:text-center"
        />
      </span>
      {t.pagination.jumpAfter && (
        <span aria-hidden className={LABEL}>
          {t.pagination.jumpAfter}
        </span>
      )}
    </span>
  )
}

/** Page links with an optional page-size select; links are `href="#"` so they are reachable from the keyboard. */
export function PaginationBar({
  page,
  pageSize,
  total,
  onPageChange,
  onPageSizeChange,
  pageSizeOptions = [10, 20, 50, 100, 300, 500],
  variant = 'default',
  label,
  className,
}: PaginationBarProps) {
  const t = useMessages(uiMessages)
  const lastPage = Math.ceil(total / Math.max(1, pageSize))
  const table = variant === 'table'
  // Only when given: an explicit undefined would remove Pagination's default name.
  const named = label === undefined ? {} : { 'aria-label': label }
  if (!table && (lastPage <= 1 || total === 0)) return null

  const go = (target: number, enabled: boolean) => (event: MouseEvent) => {
    event.preventDefault()
    if (enabled) onPageChange(target)
  }

  const sizeSelect = onPageSizeChange && (
    <div
      data-part="size"
      className="mbc:flex mbc:items-center mbc:gap-x-2 mbc:text-sm"
    >
      <Select
        value={String(pageSize)}
        onValueChange={(value) => onPageSizeChange(Number(value))}
      >
        <SelectTrigger
          className="mbc:h-8 mbc:min-w-[120px]"
          aria-label={t.pagination.pageSize}
        >
          <SelectValue />
        </SelectTrigger>
        <SelectContent>
          {pageSizeOptions.map((option) => (
            <SelectItem key={option} value={String(option)}>
              {t.pagination.perPage({ size: option })}
            </SelectItem>
          ))}
        </SelectContent>
      </Select>
    </div>
  )

  const pages = lastPage > 1 && (
    <PaginationContent className="mbc:flex mbc:items-center mbc:justify-center mbc:gap-0">
      <PaginationItem>
        <PaginationPrevious
          href="#"
          aria-disabled={page === 1 || undefined}
          className={cn(ARROW, 'mbc:rounded-r-none')}
          onClick={go(page - 1, page > 1)}
        />
      </PaginationItem>
      {getPaginationItems(page, lastPage, 7).map((item, index) =>
        Number.isNaN(item) ? (
          <PaginationItem key={`ellipsis-${index}`}>
            <PaginationEllipsis />
          </PaginationItem>
        ) : (
          <PaginationItem key={item}>
            <PaginationLink
              href="#"
              isActive={item === page}
              onClick={go(item, item !== page)}
              className={cn(
                'mbc:hover:text-primary mbc:flex mbc:h-8 mbc:w-8 mbc:items-center mbc:justify-center mbc:rounded-none mbc:text-sm mbc:transition-colors mbc:duration-200',
                item === page &&
                  'mbc:border-primary mbc:bg-primary/5 mbc:text-primary mbc:border'
              )}
            >
              {item}
            </PaginationLink>
          </PaginationItem>
        )
      )}
      <PaginationItem>
        <PaginationNext
          href="#"
          aria-disabled={page >= lastPage || undefined}
          className={cn(ARROW, 'mbc:rounded-l-none')}
          onClick={go(page + 1, page < lastPage)}
        />
      </PaginationItem>
    </PaginationContent>
  )

  if (!table)
    return (
      <Pagination {...named} className={cn('mbc:mt-4', className)}>
        {sizeSelect}
        {pages}
      </Pagination>
    )
  return (
    <Pagination
      {...named}
      className={cn(
        'mbc:flex-wrap mbc:items-center mbc:justify-end mbc:text-sm',
        className
      )}
    >
      <span data-part="total" className={cn(LABEL, 'mbc:font-medium')}>
        {t.pagination.total({ count: total })}
      </span>
      {pages}
      {sizeSelect}
      {lastPage > 1 && (
        <JumpToPage lastPage={lastPage} onPageChange={onPageChange} />
      )}
    </Pagination>
  )
}
```

```tsx
'use client'

import { useMessages } from '@mbc-cqrs-serverless/ui-web'

import { dateParts } from '../core/list'
import type { MasterField } from '../core/types'
import { masterDataMessages } from '../i18n/master-data-messages'

function parseJson(value: string): unknown {
  try {
    return JSON.parse(value) as unknown
  } catch {
    return undefined
  }
}

const text = (value: unknown) =>
  value === undefined || value === null
    ? null
    : typeof value === 'object'
      ? JSON.stringify(value)
      : String(value)

/** One list cell, formatted by the field's type as v0's data list did. */
export function DataCell({
  field,
  value,
}: {
  field: MasterField
  value: unknown
}) {
  const t = useMessages(masterDataMessages)
  switch (field.dataType) {
    case 'json': {
      // v0 showed only stored objects; a JSON string is shown the same way.
      const parsed = typeof value === 'string' ? parseJson(value) : value
      if (
        parsed === null ||
        typeof parsed !== 'object' ||
        Object.keys(parsed).length === 0
      )
        return (
          <span className="mbc:text-muted-foreground mbc:italic">
            {t.list.emptyJson}
          </span>
        )
      return (
        <pre className="mbc:bg-muted mbc:max-h-24 mbc:overflow-y-auto mbc:rounded-md mbc:p-2 mbc:text-xs">
          <code>{JSON.stringify(parsed, null, 2)}</code>
        </pre>
      )
    }
    case 'boolean':
      return value === undefined || value === null ? null : (
        <>{String(value === true || value === 'true')}</>
      )
    case 'array':
      return <>{Array.isArray(value) ? JSON.stringify(value) : text(value)}</>
    case 'date': {
      const parts = dateParts(value)
      return <>{parts ? t.list.date(parts) : text(value)}</>
    }
    default:
      return <>{text(value)}</>
  }
}
```

```ts
'use client'

import { useState } from 'react'

/**
 * Search inputs typed but not yet applied. They follow the applied filters
 * when those change from outside (a cleared search, the browser's back
 * button driving a URL-backed state).
 */
export function useFilters<F extends Record<string, string | boolean>>(
  applied: F
): [F, (next: F) => void] {
  const [draft, setDraft] = useState(applied)
  const [source, setSource] = useState(applied)
  const changed = (Object.keys(applied) as (keyof F)[]).some(
    (key) => applied[key] !== source[key]
  )
  if (changed) {
    setSource(applied)
    setDraft(applied)
  }
  return [changed ? applied : draft, setDraft]
}
```

```tsx
  rows: T[],
  sort: ListSort | undefined,
  value: (row: T, column: string) => string | number

  if (!sort) return rows

    const x = value(a, sort.column)
    const y = value(b, sort.column)
    const order = x < y ? -1 : x > y ? 1 : 0
```

```tsx
function FieldTypes() {
  const t = useMessages(masterMessages)
  return (
    <ul>
      {MASTER_FIELD_TYPES.map((type) => (
        <li key={type}>{t.fieldTypes[type]}</li>
      ))}
    </ul>
  )
}

const routing: MasterRouting = {
  href: (target) => `/master/${target.screen}`,
  navigate: () => {},
}

const parsed = parseMasterSetting({
  id: 'MASTER#tenant-a#MASTER_SETTING#PRODUCT',
  pk: 'MASTER#tenant-a',
  sk: 'MASTER_SETTING#PRODUCT',
  code: 'PRODUCT',
  name: '商品',
  version: 1,
  attributes: {
    fields: [
      {
        physicalName: 'code',
        name: 'コード',
        dataType: 'string',
        isShowedOnList: true,
      },
      {
        physicalName: 'name',
        name: '名称',
        dataType: 'string',
        isShowedOnList: true,
      },
    ],
  },
})
if (!parsed.success) throw parsed.error
const setting = parsed.data

/** master-web's client entry and the new ui-web parts, rendered on the server and hydrated. */
export function MasterScreens() {
  return (
    <MbcProvider locale="ja">
      <FieldTypes />
      <MasterLink routing={routing} to={{ screen: 'settings' }}>
        master settings
      </MasterLink>
      <BulkImportDialog screen="settings" onImport={async () => {}} />
      <MasterSettingList
        items={[
          {
            id: setting.id,
            pk: setting.pk,
            sk: setting.sk,
            code: 'MASTER_SETTING#PRODUCT',
            name: setting.name,
          },
        ]}
        total={1}
        state={initialSettingListState()}
        onStateChange={() => {}}
        routing={routing}
      />
      <MasterDataList
        setting={setting}
        items={[
          {
            id: 'MASTER#tenant-a#PRODUCT#P-001',
            pk: 'MASTER#tenant-a',
            sk: 'PRODUCT#P-001',
            masterCode: 'P-001',
            name: 'りんご',
          },
        ]}
        total={1}
        state={initialDataListState()}
        onStateChange={() => {}}
        routing={routing}
      />
      <MultiSelect
        options={[{ value: 'a', label: 'A' }]}
        value={['a']}
        onValueChange={() => {}}
      />
    </MbcProvider>
  )
}
```
