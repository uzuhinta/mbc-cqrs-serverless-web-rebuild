**Goal:** Ship master-web's `/mbc` entry: `createMasterApi`, which talks to the master backend through client-web, and the React hooks built on it. M7c adds the connected pages.

**Architecture:**

- **`createMasterApi(client, { paths })`.** It groups the backend's endpoints: settings, data, bulk, sequence, copy. Every id is URL-encoded in its path, and a host can point any group at its own path.
  - **Reads** are plain HTTP and are parsed with `/core`.
  - **Writes** are client-web commands. Each waits for its `finish:FINISHED` message, and a write that changed nothing counts as done, as in survey-web.
- **Bulk import (`mbc/bulk.ts`).** It sends batches of 100 (the backend's limit), one after another. Each batch waits for the items it changed, and progress counts across batches. A failed batch stops the import with a `MasterBulkError` naming its items.
- **Hooks (`mbc/hooks.ts`).** They use client-web's `useQuery` and `useCommand`, like survey-web's. The copy result hooks can poll, and they keep their rows on screen while they reload.
- **The `/mbc` entry.** It also re-exports what a host needs from client-web, so a host that installs only master-web shares one `MbcClientProvider` context. master-web now depends on client-web, and a build test keeps client-web out of the root, `/core` and `/editors`.

**Tech Stack:** TypeScript ~6.0, React 18/19, client-web (`createMbcClient`, `command`, `useQuery`, `useCommand`), Vitest + jsdom + Testing Library, pnpm 10 workspace, Node 24.13 via fnm.

**Spec:** `docs/superpowers/specs/2026-10-06-master-web-rebuild-design.md` §3.4 (API, writes, hooks), §5 (sequence requests), §6 (`/mbc` tests). Orchestrator: `docs/superpowers/plans/2026-10-06-m0-master-orchestrator.md`, sub-plan M7b.

## Rulings already made (do not undo)

- **`codeExists`, not `checkCode`.** It answers what the backend's `check-exist` answers: `true` when the code is taken. The screens' `checkCodeUnique` wants the opposite, so M7c's pages negate it. Task 3 updates the spec's name.
- **A write that changed nothing counts as done.** client-web rejects it with `MbcApiError` and a 2xx status; the API ignores that one error, as survey-web does.
- **Bulk import sends one batch at a time.** A failed batch stops the import. Its `MasterBulkError` keeps the batch's own message, which the import dialog shows. Progress has already reported `done`, which the dialog turns into "N of M imported".
- **The sequence code is `settingCodeOf(setting)`** in `typeCode` and `params.code1`. v0 sent the setting's raw `code`, which the detail endpoint gives without the `MASTER_SETTING#` prefix, so the requests are the same.
- **The default sequence paths are v0's host paths,** `/api/sequence` and `/api/sequence/with-provided-setting`, as the spec says. A host on the plain package sets `paths`.
- **The copy hooks keep their last rows while they reload,** and poll only when `pollMs` is set. The other hooks show a reload as loading, as the lists expect.
- **Tests use a fake client** whose `command` acts like client-web's: it calls `requestIdOf`, `expectedFinishes` and `onProgress`. One bulk test goes through a real `createMbcClient` with a fake `fetch`. client-web's fake WebSocket is not imported across packages.
- **No pages here.** M7c builds the seven connected pages, the playground's fake master backend, and the smoke render.

import type {
  CommandOptions,
  CommandRequest,
  MbcClient,
} from '@mbc-cqrs-serverless/client-web'
import { vi, type Mock } from 'vitest'

type Respond = (request: CommandRequest) => unknown

/**
 * An MbcClient whose `get`, `post` and `command` are mocks. `command`
 * behaves like client-web's: it answers with `respond(request)` (or throws
 * it, when it is an error), then reports one finish per expected item.
 */
export function createFakeClient(
  respond: Respond = () => ({ requestId: 'req-1' })
): MbcClient & { get: Mock; post: Mock; command: Mock } {
  const unused = () => {
    throw new Error('not used by /mbc')
  }
  const command = vi.fn(
    async (request: CommandRequest, options: CommandOptions = {}) => {
      const data = respond(request)
      if (data instanceof Error) throw data
      const requestId = options.requestIdOf
        ? options.requestIdOf(data)
        : (data as { requestId?: string } | null)?.requestId
      const expected =
        typeof options.expectedFinishes === 'function'
          ? options.expectedFinishes(data)
          : (options.expectedFinishes ?? 1)
      for (let finished = 1; finished <= expected; finished++)
        options.onProgress?.(finished, expected, {
          id: requestId ?? '',
          tenantCode: 'tenant-a',
          action: 'command-status',
          content: { status: 'finish:FINISHED' },
        })
      return { data, requestId }
    }
  )
  return {
    get: vi.fn(),
    post: vi.fn(),
    command,
    put: vi.fn(unused),
    patch: vi.fn(unused),
    delete: vi.fn(unused),
    messages: undefined,
    tenantCode: () => 'tenant-a',
    close: () => {},
  } as unknown as MbcClient & { get: Mock; post: Mock; command: Mock }
}

```ts
import type { CommandOptions, MbcClient } from '@mbc-cqrs-serverless/client-web'

import type { BulkJsonItem } from '../core/bulk'

/** The backend's limit for one `POST /api/master-bulk`. */
export const BULK_BATCH_SIZE = 100

export type BulkImportOptions = Pick<
  CommandOptions,
  'signal' | 'onPhase' | 'timeoutMs'
>

/**
 * A bulk import that stopped at a batch. The `done` items before it went
 * in; items `from`–`to` (1-based) and the ones after did not, or, after a
 * timeout, may have. `message` and `cause` are the batch's own error.
 */
export class MasterBulkError extends Error {
  override name = 'MasterBulkError'
  readonly done: number
  readonly from: number
  readonly to: number

  constructor(
    cause: unknown,
    range: { done: number; from: number; to: number }
  ) {
    super(cause instanceof Error ? cause.message : String(cause), { cause })
    this.done = range.done
    this.from = range.from
    this.to = range.to
  }
}

/** The request ids of a batch's changed items (unchanged ones have none). */
function changed(data: unknown): string[] {
  if (!Array.isArray(data)) return []
  return data
    .map((item) => (item as { requestId?: unknown } | null)?.requestId)
    .filter((id): id is string => typeof id === 'string' && id !== '')
}

/**
 * Sends `items` in batches of 100, one after another. Each batch is a
 * command that finishes once per changed item; a batch with no change
 * finishes at once. `onProgress(done, total)` counts across batches.
 */
export async function importBulk(
  client: MbcClient,
  path: string,
  items: readonly BulkJsonItem[],
  onProgress?: (done: number, total: number) => void,
  options: BulkImportOptions = {}
): Promise<void> {
  const total = items.length
  let done = 0
  for (let start = 0; start < total; start += BULK_BATCH_SIZE) {
    const batch = items.slice(start, start + BULK_BATCH_SIZE)
    try {
      await client.command<unknown>(
        { method: 'POST', path, body: { items: batch } },
        {
          ...options,
          // The changed items of one request share its request id.
          requestIdOf: (data) => changed(data)[0],
          expectedFinishes: (data) => changed(data).length,
          onProgress: (finished) => onProgress?.(done + finished, total),
        }
      )
    } catch (error) {
      throw new MasterBulkError(error, {
        done,
        from: start + 1,
        to: start + batch.length,
      })
    }
    done += batch.length
    onProgress?.(done, total)
  }
}
```

  type CommandOptions,

export type MasterApiPaths = {

const SETTING_MARKER = '#MASTER_SETTING#'

/** A setting's code from its id (`MASTER#<tenant>#MASTER_SETTING#<code>`). */
export function settingCodeOfId(id: string): string {
  const at = id.indexOf(SETTING_MARKER)
  return at < 0 ? id : id.slice(at + SETTING_MARKER.length)
}

const encode = encodeURIComponent

/** v0's sort parameter: the column, `-` first for descending. */
const orderBys = (sort?: ListSort) =>
  sort ? [`${sort.desc ? '-' : ''}${sort.column}`] : undefined

const filter = (value: string) => value.trim() || undefined

function pageOf<T>(answer: unknown): MasterListPage<T> {
  const { items, total } = (answer ?? {}) as {
    items?: unknown
    total?: unknown
  }
  return {
    items: Array.isArray(items) ? (items as T[]) : [],
    total: typeof total === 'number' ? total : 0,
  }
}

function parsed<T>(result: ParseResult<T>): T {
  if (!result.success) throw result.error
  return result.data
}

function tasksOf(answer: unknown): CopyTask[] {
  if (!Array.isArray(answer)) return []
  return answer.filter((task): task is CopyTask => {
    const { id, pk, sk } = (task ?? {}) as Partial<CopyTask>
    return (
      typeof id === 'string' && typeof pk === 'string' && typeof sk === 'string'
    )
  })
}

/** A write that changed nothing gets no request id: there is nothing to wait for. */
function isUnchanged(error: unknown): boolean {
  return (
    error instanceof MbcApiError && error.status >= 200 && error.status < 300
  )
}

export function createMasterApi(
  client: MbcClient,
  options: MasterApiOptions = {}
): MasterApi {
  const paths = { ...DEFAULT_MASTER_API_PATHS, ...options.paths }
  const write = async (request: CommandRequest, settings?: WriteOptions) => {
    try {
      await client.command(request, settings)
    } catch (error) {
      if (!isUnchanged(error)) throw error
    }
  }
  const exists = async (path: string, signal?: AbortSignal) =>
    (await client.post<unknown>(path, undefined, { signal })) === true

  return {
    settings: {
      async list(state, { signal } = {}) {
        return pageOf(
          await client.get<unknown>(`${paths.setting}/list`, {
            query: {
              code: filter(state.code),
              name: filter(state.name),
              keyword: filter(state.keyword),
              page: state.page,
              pageSize: state.pageSize,
              orderBys: orderBys(state.sort),
            },
            signal,
          })
        )
      },
      async get(id, { signal } = {}) {
        return parsed(
          parseMasterSetting(
            await client.get<unknown>(`${paths.setting}/detail/${encode(id)}`, {
              signal,
            })
          )
        )
      },
      create: (body, settings) =>
        write({ method: 'POST', path: paths.setting, body }, settings),
      update: (id, body, settings) =>
        write(
          { method: 'PUT', path: `${paths.setting}/${encode(id)}`, body },
          settings
        ),
      delete: (id, settings) =>
        write(
          { method: 'DELETE', path: `${paths.setting}/${encode(id)}` },
          settings
        ),
      codeExists: (code, { signal } = {}) =>
        exists(`${paths.setting}/check-exist/${encode(code)}`, signal),
    },
    data: {
      async list(settingCode, state, { signal } = {}) {
        return pageOf(
          await client.get<unknown>(`${paths.data}/list`, {
            query: {
              settingCode,
              code: filter(state.code),
              keyword: filter(state.keyword),
              isDeleted: state.isDeleted,
              page: state.page,
              pageSize: state.pageSize,
              orderBys: orderBys(state.sort),
            },
            signal,
          })
        )
      },
      async get(id, { signal } = {}) {
        return parsed(
          parseMasterData(
            await client.get<unknown>(`${paths.data}/detail/${encode(id)}`, {
              signal,
            })
          )
        )
      },
      create: (body, settings) =>
        write({ method: 'POST', path: `${paths.data}/create`, body }, settings),
      update: (id, body, settings) =>
        write(
          { method: 'PUT', path: `${paths.data}/${encode(id)}`, body },
          settings
        ),
      delete: (id, settings) =>
        write(
          { method: 'DELETE', path: `${paths.data}/${encode(id)}` },
          settings
        ),
      restore: (id, settings) =>
        write(
          {
            method: 'PUT',
            path: `${paths.data}/${encode(id)}`,
            body: { isDeleted: false },
          },
          settings
        ),
      codeExists: (settingCode, code, { signal } = {}) =>
        exists(
          `${paths.data}/check-exist/${encode(settingCode)}/${encode(code)}`,
          signal
        ),
    },
    bulk: {
      importItems: (items, onProgress, settings) =>
        importBulk(client, paths.bulk, items, onProgress, settings),
    },
    sequence: {
      async generateCode(field, setting, { signal } = {}) {
        const code = settingCodeOf(setting)
        const formatted = Boolean(field.formatCode)
        const answer = await client.post<{ formattedNo?: unknown } | null>(
          formatted ? paths.sequenceWithSetting : paths.sequence,
          {
            tenantCode: client.tenantCode(),
            // v0: the format's own sequence, or one sequence per setting.
            typeCode: field.formatCode || `MASTER_SETTING#${code}`,
            rotateBy: 'none',
            params: { code1: code },
            prefix: field.prefix,
            postfix: field.postfix,
            ...(formatted && { format: field.dataFormat }),
          },
          { signal }
        )
        if (typeof answer?.formattedNo !== 'string')
          throw new MbcApiError(
            200,
            answer,
            'The sequence response has no formattedNo'
          )
        return answer.formattedNo
      },
    },
    copy: {
      async request(body, { signal } = {}) {
        await client.post(paths.copy, body, { signal })
      },
      async tasks(settingCode, { signal } = {}) {
        const answer = await client.get<unknown>(
          `${paths.tasks}/sfn-task-parent`,
          { query: { masterSettingCode: settingCode }, signal }
        )
        // The backend matches the code as a prefix: PRODUCT also finds PRODUCT2.
        return tasksOf(answer).filter((task) =>
          copyTaskName(task).startsWith(`${settingCode}#`)
        )
      },
      async task(id, { signal } = {}) {
        // The backend lists the tasks under the key's parent, so v0 sends a
        // child's key: the request's id plus "#0".
        return tasksOf(
          await client.get<unknown>(`${paths.tasks}/${encode(`${id}#0`)}`, {
            signal,
          })
        )
      },
    },
  }
}

/**
 * A query that reloads every `pollMs` ms, and keeps showing its last data
 * while a reload runs, so rows stay on screen.
 */
function usePolled<T>(
  key: string,
  load: ((signal: AbortSignal) => Promise<T>) | null,
  pollMs: number | undefined
): QueryState<T> {
  const query = useQuery(key, load)
  const { refetch } = query
  const active = load !== null
  useEffect(() => {
    if (!active || !pollMs) return
    const timer = setInterval(refetch, pollMs)
    return () => clearInterval(timer)
  }, [active, pollMs, refetch])
  const [kept, setKept] = useState<{ key: string; data: T }>()
  if (
    query.data !== undefined &&
    (kept?.key !== key || kept.data !== query.data)
  )
    setKept({ key, data: query.data })
  const data = query.data ?? (kept?.key === key ? kept.data : undefined)
  return { ...query, data }
}
